# 境界の一覧(L2.4 の5。章・部の境界まで。構造の記録であり評価ではない)

本文は見出しを持たない(依頼者の指定)。段落ごとに番号を振る(P1〜P5)。章・部は、承認済みの構成案(4章)の並びと、段落の初めの語句から拾った。節・項・話題の境界は、構造担当が検出する。

| 登録単位 | 位置 | 冒頭の語句 | 起こす変化(構成案から) |
| --- | --- | --- | --- |
| 文書全体 | P1〜P5 | 「大人がかくれんぼうを遊ばなくなるのは、体力や時間・場所・相手の問題よりも」 | 読者が、大人がかくれんぼうを遊ばなくなる理由を、書き手の示す一つの説明として分かる(一文で言い直せる) |
| 章1 | P1 | 「大人がかくれんぼうを遊ばなくなるのは」 | 答えと、「名目」が何を指すかが分かる |
| 章2 | P2 | 「大人の集まりで「かくれんぼうをしよう」と」 | 名目のない集まりで遊びが始まらない場面を、経験と照らして思い浮かべられる |
| 章3 | P3〜P4 | 「では、名目があればどうか。」 | 名目があれば同じ大人は遊ぶこと、体力・時間・場所・相手の説明では分かれ目を説明できないことが分かる |
| 章4 | P5 | 「大人が夢中になる遊びもある。」 | 名目のある遊びは大人も続けること、説明が及ぶ範囲が分かり、答えを一文で言い直せる |

決まらなかった境界:P3 と P4 を一つの章とするか、別の章とするか(構成案は一つの章。段落は2つ)。構造担当が決める。
