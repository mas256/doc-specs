# 要約テストの結果(レビュー回1)

## 1. 読み終えた読者に分かること・できるようになること

- 分かること:大人が日常の場で自分たちのかくれんぼうをしなくなるのは、見つかるかどうか分からない不確かさが、成長によって失われるからだと分かる。忙しさや人目などのよくある理由は、機会の話にすぎないと分かる。
- できるようになること:「大人がかくれんぼうをしない」という現象を、機会ではなく遊びの仕組み(不確かさの源)から説明できる。子どもが不確かさを持つ理由(体の小ささと幼さ)と、成長がそれを奪う過程を、反例を含めて自分の言葉で説明できる。

## 2. 全体を貫く問いと答え

- 問い:なぜ大人は、日常の場で自分たちのかくれんぼうをしなくなるのか。
- 答え:かくれんぼうの面白さは「見つかるかどうか分からない」不確かさにあり、子どもはその源を体の小ささと幼さから得ている。成長はその二つを使い尽くすため、日常の場で大人の遊びとしてのかくれんぼうは成り立たなくなる。

## 3. 各章(段落)の役割

- 段落1:結論を先に示す。大人がかくれんぼうをしなくなる理由を、不確かさの喪失として提示する。
- 段落2:よくある理由(忙しさ、仲間、人目、隠れ場所)を機会の話として退け、理由を遊びの仕組みに求める方針を示す。
- 段落3:かくれんぼうの仕組み(鬼が数える間に隠れ、探し、勝敗は見つかるかの一点で決まる)を示し、面白さが不確かさに集まることを述べる。
- 段落4:不確かさの源を子どもについて二つ挙げる(体の小ささ、相手の考えを読み切れない幼さ)。同じ日常の場が子どもには広く見えることを説明する。
- 段落5:成長が二つの源を奪う過程を説明する。鬼が候補を順に調べられるようになり、勝敗が「いつ見つかるか」に変わって遊びが成り立たなくなることを示す。
- 段落6:反例を説明する。大人になる前にやめる子や、大人が広い場や道具、ルールで不確かさを作り直して楽しむ別の遊びが、本論の説明と合うことを示す。
- 段落7:結論を繰り返してまとめる。子どもの体の小ささと幼さを、成長が使い尽くすことが理由だとする。
