# 要約テストの回答

## 1. 読み終えた読者に、何が分かり、何ができるようになるか

- 分かること: 割り算は「掛けて元に戻る数」を答えとする定義である。0で割ると、戻る数が一つもない(5÷0)か、一つに決まらない(0÷0)ため、定義が答えを与えない。これは「禁止されている」のではなく「定義されていない」ということである。5÷0 を1などと決めても、掛け算の逆という定義を保つ限り決められない。
- できること: 「5÷0 に答えがないのは、0にどの数を掛けても5にならないからだ」と、自分の言葉で説明できる。

## 2. この文章全体を貫く問いと、その答え

- 問い: 「0で割ってはいけない」のは、なぜか。
- 答え: 割り算は掛け算の逆として定義されている。0で割ると、掛けて元に戻る数が存在しない(5÷0)か、一つに決まらない(0÷0)。そのため定義は答えを与えられない。禁止されているのではなく、定義されていないからである。

## 3. 各段落の役割

1. 導入: 「0で割ってはいけない」を覚えているだけで、理由を考えたことがあるかと問い、割り算の定義から理由を見直すと予告する。
2. 割り算の定義を示す: 12÷3=4 を掛け算で確かめ、掛けて元に戻る数を答えとする定義と、式 (割る数)×□=(割られる数) を示す。
3. 5÷0 の検討: □に1、2、100などを入れても 0×□=0 となり、5に戻る数が一つもないことを示す。
4. 0÷0 と 0÷5 の対比: 0÷0 は戻る数が一つに決まらず、0÷5 は答えが0に決まることを示す。
5. 区別の提示: 0で割るとき定義が答えを与えないのは、禁止ではなく定義がない場合だと区別する。
6. 反論への応答: 5÷0=1 と決める案は、掛け算の逆という定義を保つ限り成り立たず、逆を手放すと割り算が掛け算の逆ではなくなると示す。
7. まとめと確認: 流れを自分の言葉で言えるかを促し、5÷0 に答えがない理由を一文で言えるか確かめさせる。
