# 要約: かくれんぼうを大人が遊ばなくなる理由(kakurenbo-v1.md)

## 1. 読み終えた読者に分かること・できること

- 大人がかくれんぼうを遊ばなくなる理由は、体力・時間・場所・相手の不足ではなく、「名目」がないことだと分かる。
- 「名目」とは、遊ぶことを自分にも周りにも説明できる理由をいう(例: 子どもに付き合う、余興として)。
- 同じ集まりでも、言い出しだけでは場が止まり、名目が与えられると遊び始める例から、この説明を確かめられる。
- 勝負の遊び(ボードゲームなど)が大人に好まれることも、名目(勝負)で同じ説明が当てはまると判断できる。
- 大人の遊びの有無を、体力や環境ではなく名目の有無という観点から分析できるようになる。

## 2. 全体を貫く問いと答え

- 問い: 大人がかくれんぼうを遊ばなくなるのはなぜか。
- 答え: 大人が遊ぶには名目が要るが、名目のない大人どうしのかくれんぼうにはそれがないから。体力・時間・場所・相手は、名目の有無にかかわらず変わらないため、遊ぶかどうかを分ける理由にはならない。

## 3. 各章(段落のまとまり)の役割

1. 第1段落: 問いへの答えを示し、「名目」の意味を定義する。以後の議論で使う言葉を定める。
2. 第2段落: 名目のない大人の集まりでは、遊びの誘いが冗談として流されることを示し、相手や場所がそろっていても遊べないことから、それらが理由ではないと論じる。
3. 第3段落: 名目(子どもに付き合う、余興)が与えられると大人が遊ぶ例を示し、名目の有無が遊ぶかどうかを分ける違いだと特定する。
4. 第4段落: 体力・時間・場所・相手は名目の有無で変わらないことを指摘し、かくれんぼうの性質(隠れ場所と読み合い)からも体力の衰えは理由でないと退ける。
5. 第5段落: 勝負の遊びが大人に夢中になられる例を、名目(勝負)で説明できると示して反例を退け、最後に結論を繰り返して論を閉じる。
