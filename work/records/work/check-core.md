# 検証結果:中心になる数学の事項(書く側の要求つき・U1.4)

作業パケット:work/packet-check-1.md。担当:検証担当。範囲:C1〜C9(数と式は実数の範囲)。
根拠の種別は CHK(再導出・代入・スクリプト)と EXT(外部資料)。外部資料の取得について:en.wikipedia.org と mathworld.wolfram.com は、この環境のネットワーク許可の外で取得できなかった(WebFetch が名前解決に失敗)。そのため、外部資料は WebSearch が返した抜粋・要約だけで確かめた(原典の全文は読んでいない)。

C1|確認済|b≠0 のとき、b×x=a は両辺に b の逆数を掛けて x=a/b と一つに決まる(再導出)。b=3,−2,1/5、a=12,0,−7 の分数計算で、b×(a/b)=a と、別の値(a/b+1/7)では成り立たないことをスクリプトで確かめた。例は 12÷3=4、3×4=12 で一致(CHK)。
C2|確認済|分配法則と 0+0=0 から 0×x=(0+0)×x=0×x+0×x。両辺から 0×x を引いて 0×x=0(再導出)。x=0,5,−3,1/7 の代入でも 0(スクリプト。CHK)。
C3|確認済|C2 より 0×□は常に 0 で、a≠0 なら 0×□=a は成り立たない(再導出)。x=0,5,−3,1/7 を試し、0×x=5 になる x がないことも確認(CHK)。
C4|確認済|C2 より、どの実数□でも 0×□=0 が成り立つ。解は全実数で一つに決まらない(再導出。代入でも確認。CHK)。
C5|確認済|0×c=a(a≠0)を保つと、C2 の 0×c=0 より a=0 となり、a≠0 に反する(背理法による再導出。CHK)。
C6|誤り|言い方が正確でない。正しくは次のとおり。(1)「∞ は実数ではなく、実数の四則の決まりがそのままは使えない」は正確。(2)「拡大実数直線」は一般に +∞ と −∞ の2つを足した体系を指し、そこでは 1÷0 は通常「未定義」で、∞ とは書かない(1/x の x→0 の極限が左右で +∞/−∞ に分かれるため)。1÷0=∞ とする流儀は、∞ を1点だけ足す「射影拡大実数直線」と「リーマン球面」(複素数の側。実数なら射影直線)に当たる。(3)「0×∞ に決まった値がない」は、拡大実数直線・射影拡大実数直線・リーマン球面のどれでも 0×∞ を未定義とするのが通例だが、測度論では 0×∞=0 と約束する文脈がある。そこで「決まった値がない」は「通例は未定義とされる」と言うのが正確。(4)射影拡大実数直線・リーマン球面は体ではない。0÷0 と ∞÷∞ も未定義。推す言い方:「射影拡大実数直線やリーマン球面では、1÷0 を ∞ と書く流儀がある。ただし ∞ は実数ではなく、実数の四則の決まりがそのままは使えない(たとえば 0×∞ は通例、未定義とされる)」。典拠:Wikipedia「Extended real number line」(抜粋:1/0 は通例未定義、0×±∞ は不定形で通例未定義、測度論では 0 とする例外あり)、同「Projectively extended real line」(体でなく、0×∞ は未定義)、同「Riemann sphere」(z/0=∞(z≠0)、0/0 と ∞/∞ は未定義)、nLab「extended real number」(いずれも WebSearch の抜粋。原典の全文は未取得。EXT)。
C7|確認済|体の公理(分配法則、0≠1 を含む)から 0×y=0(C2 と同じ導出)。0 に逆元 y(0×y=1)があると 0=1 となり、0≠1 に反する。ゆえに 0 に逆元はない(再導出。CHK)。注:導出には「体では 0≠1」を使う。PhysicsForums の解説も同じ筋(EXT。補助)。
C8|確認済|Casio の取扱説明書(support.casio.com の fx-991ZA PLUS II、fx-570MY CW など複数機種)に、ゼロでの割り算を含む不正な計算で「Math ERROR」を表示すると書かれている(EXT。WebSearch の抜粋)。機種差:表示の文言は機種で異なる(Casio の関数電卓は「Math ERROR」。機種によっては「E」や「Error」)。「E」「Error」の機種は、今回の資料では確かめていない。他社(TI など)の機種は、資料が見つからず未確認。「多くの電卓で、5÷0 はエラー表示になる。文言は機種で異なる」までは言える。
C9|未確認|教科書・解説書の原典に当たれなかった。理由:Wikipedia と MathWorld は取得できず、取得できた範囲は WebSearch の抜粋(解説記事や教育サイト)だけで、数学の教科書の原典は見つからなかった。参考の所見(確認済ではない):数学の専門的な解説(体の公理、「0 は掛け算の逆元を持たない」)では「定義されていない/未定義」が標準で、「禁止/許されない」は小学校・中学校向けの教育資料に多い言い方と見える。本文が「定義されていない」の見方を採ることと矛盾する資料は、今回は見つからなかった。確かめるには、体の公理を載せた教科書(大学1年の代数・解析)の該当箇所か、MathWorld の「Division by Zero」の取得が要る。
