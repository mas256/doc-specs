# 壁打ち(中身)のロールモデルの読み:なぜ0で割ってはいけないのか(切り口2組)

根拠:要件定義書(brief.md。承認済み)のロールモデルの原文、切り口の一覧(angles-result.md)、題材の一覧(topics-result.md)。挙げるのは候補であり、判定はしない。切り口の採否と優劣、核が反論に耐えるか、分量1100字の中で本文が答えられるかは、この段では判断しない。反例と別の説明は、ロールモデル(中学3年生の一人)の言葉で書く。

## 切り口1

切り口の名前: 割り算は掛け算の逆(依頼者の視点)
主張の核を読んで、この人物が止まる箇所:
- 「割り算の約束」(A-7):割り算は計算のやり方だと思っていて、約束として決めたものだとは考えたことがない。「割り算の答えを、掛けて元に戻る数と決めた約束」で、何を決めたのかが分からなくなる。
- 「掛けて5に戻る数が一つもなく」から「約束では答えが決まらず」へ進む一歩:答えが見つからないことは分かるが、そこから「約束が答えを与えない」と言い換える理由が分からない。
- 「定義されていない」:「定義」は覚える用語の説明だと思っているので、「定義されていない」を、説明が書かれていない、くらいに読みそうである。「禁止ではなく」との違いが、言い方の違いにしか見えない。
思いつく反例:
- 「0÷5 は0になるのだから、0÷0 も0でいいんじゃないの?」
- 「でも、先生は『0で割ってはいけない』と言った。やっぱり禁止されているんじゃないの?」
- 「電卓がエラーを出すのは、電卓がそう作られているからで、数学の約束とは関係ないのでは?」
思いつく別の説明:
- 「0で割ってはいけないのは、そう決まっているから覚えるだけで、理由はいらないのでは?」
- 「0で割れないのは、答えがないから、というだけでいい。約束の話を持ち出さなくても説明できる」
論証の穴だと感じる箇所: 「なぜ割り算を『掛けて戻る数』という約束にしたのか」が、核の中で示されていない(約束なら別の決め方もできそうに見える)。このため「その約束のままでは決まらない」の「その約束」が、動かせないものに見えない。
身近な事柄か:
- A-7(割り算の約束):身近でない。割り算を使うことはあっても、約束として見たことがない。
- B-1(往復で確かめる):身近。12÷3=4 と 3×4=12 は、この人物が確かめられる式である。
- B-4(5÷0の往復):身近。0×□=5 の□に数を入れる操作は、この人物にできる(0×□ がどれも0になるのは、確かめれば分かる)。
- B-5(0÷0の往復):やや身近。0×□=0 に数を入れる操作はできるが、「答えが無数にある」ことを答えが決まらないと見る見方は、考えたことがない。
加わる解釈は新しいか: 新しい。「0で割ってはいけない」を、禁止ではなく、約束が答えを与えないことと見る見方は、先生に言われて覚えただけの人物にはない。「割り算を掛けて元に戻る数と捉える」ことは、12÷3=4 の確かめとして、すでに知っている。

## 切り口2

切り口の名前: 0を掛けると戻る道が消える
主張の核を読んで、この人物が止まる箇所:
- 「どの数も0に集まって戻る道が失われる」:「集まる」「戻る道」が何を指すのか、式で言い直せない。0×4=0、0×5=0 と並べれば分かりそうだが、核の一文の中では比喩に見える。
- 「割り算は『掛け算で元に戻る数』を答えとする約束であり」:切り口1の核と同じく、割り算が約束だという一歩で止まる。
- 「この約束のままでは0で割る答えを決められず」:「のまま」が何を残して何を変えるのかが分からない。
思いつく反例:
- 「0×4=0 でも、0÷0 は4に戻ると考えてもよいのでは? 戻る数が多すぎるだけで、戻る道はあるのでは?」(「道が消える」と言い切ることへの引っかかり)
- 「0÷5 は0になる。0を掛けて0になるから、0÷5 も0÷0 と同じように戻れないのでは?」(0が出る式を、0で割る式と取り違える)
- 「0で割れる電卓があったらどうなる?」
思いつく別の説明:
- 「12個を0人で分けようとしても、分ける相手がいない。だから0で割れない」(割り算を分ける場面で考える道)
- 「先生が禁止したから」
論証の穴だと感じる箇所: 「5÷0 は戻り着く先がない」と「0÷0 は戻り着く先が多すぎる」は、核の一文では述べられておらず、核だけでは0÷0 が定義されない理由が読み取れない(0÷0 は補足で扱う位置にある)。
身近な事柄か:
- B-1(往復で確かめる):身近。
- 新規N-2(3を掛ける往復は一本道):身近。3×4=12、3×5=15 と、12から4へ戻ることは、この人物が確かめられる。
- 新規N-1(0を掛けると、どの数も0になる):身近。0×4=0 の計算は知っている。ただし、「掛けたあとの結果から、元の数が分からなくなる」という見方は、考えたことがない。
- B-8(答えなしと答えが多すぎる):身近でない。二つを並べて見る見方に慣れていない。
加わる解釈は新しいか: 新しい。0を掛ける側から、0で割れない理由を見る見方は、この人物にない。「戻る道」という言い方は、「逆」を、操作を元に戻す意味で見せるので、「逆」を使うこの人物には新しいが、比喩として受け取られるかどうかは、この段では分からない。
