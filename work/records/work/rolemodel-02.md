# ロールモデルとして読んだ結果(壁打ち(中身)・ロールモデルの段、2回目)

- 読んだ人物:採点者A(brief.md 第2版の「ロールモデル」欄)
- 根拠にしたもの:brief.md(第2版)と packet-rolemodel-02.md だけ
- 候補:切り口4の主張の核(brief.md の「全体を貫く問いまたは主張」の欄)
- この文書は候補を挙げるだけで、核が反論に耐えるかどうかは判定しない(判定は企画の担当、採否は依頼者)。

主張の核を、次の3つの部分に分けて読んだ。以下では、どの部分に向く反例・別の説明かを [ ] で示す。

- [a] かくれんぼうの面白さは、見つかるかどうかが最後まで分からないことにある。
- [b] その不確かさは、日常の空間に比べて小さい体と、相手の考えを読み切れない幼さから生まれる。
- [c] 成長すると両方が失われ、日常の場では探せば必ず見つかる遊びになるので、大人はしなくなる。

## 1. 思いつく反例

1. 大人のサバイバルゲーム・脱出ゲーム・鬼ごっこの大会 [c]
   大人も隠れる・探す遊びをしている。核は「日常の場では」と場を限っているので、直接ぶつかるわけではない。それでも採点者は次のように考える。不確かさが場の広さで取り戻せるなら、大人は公園や山でかくれんぼうをすればよいはずだ。実際には、チーム・道具・得点・制限時間のある別の形に移っている。これは、不確かさを失ったこと以外の理由(勝ち負けの記録、ルールの複雑さ、決まった場があること)で選んでいるのではないか。
2. 小学校の高学年でもかくれんぼうをしなくなる [b][c]
   高学年の子どもの体は、まだ大人より小さい。核の言う「両方が失われる」のは大人になる時点のはずだが、実際にやめる時期はそれより早い。採点者は、体の小ささは理由として働いていないのではないかと考える。また、相手の考えを読む力がこの時期にもう育っているなら、2つの源のどちらが効いているのかを答案が分けていないところで止まる。
3. 大人どうしの読み合いの遊び・スポーツ(サッカーのPK、ポーカーのような駆け引き) [b][c]
   大人になっても、相手の考えは読み切れない。読み合いの不確かさを楽しむ遊びは、大人が盛んに行っている。採点者はさらに次の点を思いつく。成長で読む力が伸びるのは、隠れる側も探す側も同じである。そうであれば、大人どうしでは読み合いが釣り合って、不確かさは残るのではないか。核の「読み切れない幼さが失われる」には、この点が抜けているように見える。
4. 大人が幼い子どもとかくれんぼうをする場面 [c]
   親や保育者は、子どもとかくれんぼうをする。前提を「多くの大人は」と限れば外せる(brief.md の主題と範囲で許されている)。ただ、この場面では大人の体は大きく、隠れ場所が限られる。それでも子どもは楽しんでいる。これは次の5につながる。
5. 幼い子どもは、すぐ見つかる場所に隠れて、見つけてもらうのを喜ぶ [a]
   見つかるかどうかが分かりきっていても楽しんでいる例である。面白さの中心が不確かさにあるという [a] に合わない。
6. 大人が日常の場で隠れて見つからない例(広い建物、人の多い商業施設、大学の構内) [c]
   「日常の場では探せば必ず見つかる」は、大人の日常の場の広さを考えると言い過ぎではないか、と考える。

## 2. 思いつく別の説明(同じ「大人はしなくなる」を別の理由で説明する道)

1. 場所と許可:大人の日常の場(職場、店、他人の家や敷地)は、隠れることが許されない場所である。遊べないのは、不確かさがなくなったからではなく、隠れてよい場所がないからだ、という説明。
2. 人と時間:かくれんぼうには、同じ時間に空いている複数の仲間が要る。大人はそれを集めにくい(「忙しいから」に近い。採点者はこれをどの遊びにも言える理由と見るが、核の対抗馬としては思いつく)。
3. 待つことの重さ:隠れる側は、長い間動かずに待つ。大人には、その時間の機会費用が大きい。説明の向きが [a] の不確かさではなく、遊びの中の「待つ」の構造に向いている。
4. 発達の課題が済む:幼い子どもが隠れて見つけてもらう遊びは、離れることと戻ることを確かめる遊びでもある。その役目を終えると、遊ぶ理由がなくなる、という説明(5の反例と同じ源)。
5. 形を変えて続けている:隠れる・探す欲求は残り、より複雑なルールや競争の形(サバイバルゲームなど)に移っただけだ、という説明。大人は、遊びそのものをやめたのではなく、かくれんぼうという素朴な形をやめた、と読む。
6. 体の不都合:大人の体は狭い所に入りにくく、痛みや怪我の恐れがある。核の「体が大きくなる」と同じ事実から、「見つかりやすくなる」ではなく「隠れること自体がつらくなる」という別の帰結を引く道。

## 3. 止まる箇所(定義のない語、根拠のない断定)

1. 「日常の空間」「日常の場」:だれの日常か(子どもか大人か)、どの範囲かが決まっていない。大人の日常の範囲は子どもより広いので、「空間に比べて体が小さい」の比べる相手がずれて見える。
2. 「相手の考えを読み切れない幼さ」:何ができないことを指すのかが定義されていない。採点者は、子どもの発達と社会化の概念で読むが、答案の外の知識で補ってはくれない(brief.md 想定読者)。
3. 「探せば必ず見つかる」:「必ず」は根拠のない断定として止まる(反例6)。
4. 「面白さは〜にある」:不確かさが面白さの中心だという点の根拠が、核の中にはない(反例5)。採点者は、結果の不確かさが多くの遊び・スポーツに共通する面白さ(競争と偶然)だと知っている。そのため、面白さの説明そのものはかくれんぼうに固有ではない、と読む。かくれんぼうに結び付くのは、不確かさの源(体と空間、読み合い)のほうである。
5. 「その両方が失われ」:2つの源が、いつ、どの程度失われるのかを示していない(反例2・3)。

## 4. 身近な事柄か、加わる解釈は新しいか

- 身近か:身近である。かくれんぼうの遊び方を自分の経験として知っている(brief.md 想定読者)。小さいころは狭い所に隠れられたこと、大人になると隠れられる場所が少なくなることも、経験から思い当たる。「競争と偶然」「子どもの発達と社会化」も、自分で使える概念である。
- 解釈は新しいか:
  - 「勝敗の不確かさが面白さを生む」という部分は、採点者にとって新しくない。遊びの基本の概念として既に使っている。
  - 新しく見えうるのは、不確かさの源を、かくれんぼうに固有の2つ(体と空間の大きさの比、読み合いの未熟さ)に置き、成長でその源が失われることと結び付けた点である。「忙しいから」「恥ずかしいから」がどの遊びにも言える理由であるのに対し、これはかくれんぼうという対象に結び付いた理由として読める。
  - 【要確認3】「成長すると簡単に見つけられるようになるから」という形の答えが、採点者が毎年読む答案の中でどれほど多いかは、brief.md に書かれていない。多いなら、新しさは不確かさの源を2つに分けた点だけに限られる。どちらか判断できないので、推測で補わない。
