## 切り口

切り口1の主張の核|確認済|数学の主張は、5÷0 は 0×□=5 を満たす数が一つもない(C3)、0÷0 は 0×□=0 をどの数も満たし一つに決まらない(C4)、割り算の約束(掛けて元に戻る数)では答えが決まらない(C1・C5)。実数の範囲で反例はない。末尾の「禁止ではなく定義されていない」という言い方が標準かどうかは C9(未確認)の内容で、今回も確認していない。
切り口1の0÷0をどこで扱うか|確認済|C4 に同じ。0×□=0 を満たす実数は無数にある。「答えがない(5÷0)」と「一つに決まらない(0÷0)」の区別は、C3 と C4 から正しい。
切り口1の「ほかの値に決めればいい」にどう答えるか|確認済|C5 に同じ。5÷0=1 なら、掛けて戻す確かめは 0×1=0≠5 で成り立たず、1 の代わりにどの値 c でも 0×c=0≠5。「割り算の約束と食い違う」は、約束(掛けて戻る数)を保つ前提で正しい。C-4 の指摘(保たない約束なら決められる)は、この文の「約束と食い違う」とは矛盾しない。
切り口2の主張の核|確認済|C2〜C5 に同じ。0を掛けるとどの数も 0 になり(C2)、5÷0 には戻る数がなく(C3)、0÷0 には戻る数が多すぎる(C4)。実数の範囲で反例はない。注:「戻る道が失われる」は、5÷0(戻る先がない)には当てはまり、0÷0 では「戻る先が一つに決まらない」の意味になる(切り口2自身の 0÷0 の文がそう書いている)。末尾の「定義されていない」の標準性は C9(未確認)の内容。
切り口2の0÷0をどこで扱うか|確認済|C3・C4 に同じ。5÷0 は掛けても 5 にならない、0÷0 は 0×□=0 がどの数でも成り立つ。
切り口2の「ほかの値に決めればいい」にどう答えるか|確認済|C5 に同じ。0を掛ければどの数も 0 なので、5÷0 にどの値を置いても 0×(その値)=0≠5。
