# 切り口(かくれんぼう小論文。brief.md v1、topics.md、check-result.md に基づく。切り口の段)

採否は依頼者が決める。この表は候補である。問い:「かくれんぼうを大人になると遊ばなくなるのはなぜか」

使った題材の確かさ:使った題材はすべて「自分の知識だけで言える日常の事柄」(検証結果で「誤り」はなく、「確かめられなかった」題材も使っていない)。そのため「未確認を含む」組はない。題材1-6、2-6、3-6は、どの組にも使っていない(1-6は型の当てはめが未確認で、型名の説明の字数も要る。2-6は傾向が未確認。3-6は型としてのみ確認済みで、条文は書けない)。

## 切り口1

- 書き方の向き:遊ぶ本人と周りの人が持つ「大人らしさ」への意識に焦点を当て、日常の場面(誘われたときの照れ、集まりで場が一瞬止まる様子)から、遊びに入る許しが大人には与えられなくなる経過を述べる。
- 主張の核:大人がかくれんぼうを遊ばなくなるのは、遊びの面白さが消えるからではなく、「大人がそんなことをするものではない」という自分と周りの意識が、遊びに入ること自体を許さなくなるからだ。
- 主軸の題材:2-1、2-2
- 補強の題材:3-5、2-5
- 大人が遊ぶ例外の場面への備え:2-5で限定する。子どもに付き合うという名目があるときは、意識が遊びを妨げない。名目のない大人どうしの場面に主張が及ぶ、と範囲を絞る。
- 未確認を含む:なし
- 備考:体力(3-3)、相手の不在(3-4)、時間と場所(2-3)の別の説明には、この組の題材では答えていない。

## 切り口2

- 書き方の向き:大人の一日の暮らしを思い浮かべさせ、遊びに要るもの(時間、場所、隠れる理由、相手)が、子どもの頃は暮らしの中に最初からあり、大人では自分で整えるものになることを順に述べる。
- 主張の核:大人がかくれんぼうを遊ばなくなるのは、遊ぶのに要る時間・場所・隠れる理由・相手が、大人の暮らしの中では自然には用意されず、そのつど自分で整えなければならなくなるからだ。
- 主軸の題材:2-3、2-4
- 補強の題材:3-4、3-1
- 大人が遊ぶ例外の場面への備え:3-1で限定する。集まりの場では、時間・場所・相手が一度にそろうので遊ぶ、と読む。条件がそろえば遊ぶという形で、主張が成り立つ範囲を示す。
- 未確認を含む:なし
- 備考:3-4は「相手がいない」を別の説明として受け、条件の一つに組み入れる使い方である。照れ・体面(2-1、3-5)と体力(3-3)の別の説明には、この組の題材では答えていない。

## 切り口3(要件から一歩出た案:題材の元の仕組みの分析)

- 書き方の向き:かくれんぼうの面白さが、役割が逆向きの二つの立場のどんな緊張と推理でできているかを先に分解し、その面白さを大人はほかの遊びで得られるという向きから、理由を導く。
- 主張の核:大人がかくれんぼうを遊ばなくなるのは、この遊びの面白さである「見つかるか分からない緊張と、探す推理の余地」を、大人はより読み合いの深い別の遊びで得られ、かくれんぼうを選ぶ必要がなくなるからだ。
- 主軸の題材:1-2、1-3
- 補強の題材:3-2、2-5
- 大人が遊ぶ例外の場面への備え:2-5で限定する。大人が子どもに合わせて見つかりやすく隠れる(手加減)ときは、緊張と推理の余地を人為的に作り直しているので遊べる、と読む。そのうえで、主張は大人どうしが対等に遊ぶ場面に限る。
- 未確認を含む:なし
- 備考:brief.md の「他の遊びとの比較は、理由を支えるために必要な範囲でだけ扱う」に、この組は3-2を主な支えとして近く寄る(返信の確認事項を参照)。体力(3-3)は1-4で答えられるが、この組には入れていない(補強は2個まで)。

## 3組の主張の核が別の理由であること

1. 切り口1:意識(大人らしさの目が遊ぶ許しを奪う)
2. 切り口2:生活の条件(時間・場所・隠れる理由・相手が自然には用意されない)
3. 切り口3:遊びの仕組みと代わり(面白さの中身を、別の遊びで満たせる)
