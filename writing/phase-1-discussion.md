# フェーズ1：壁打ち（議論中 〜 要件定義書作成）

## 目的
依頼者の頭の中にあるモヤモヤを広げ、今回の文書で「誰に・何を届けるか」の芯を作る。

## 手順
1. **決まっていることから始める**: 依頼文や出題で既に決まっていること(字数、形式、問いそのもの)を先に確かめ、依頼者の言葉(どんな読者を思い浮かべているか、何が気になっているか)を引き出す。そこから逆算して、芯(読者、読後に期待すること、切り口)へ進む。要件定義書の欄の順には尋ねない。
2. **議論中として対話する**: 承認を求めず、オープンクエスチョン・視点の追加・広く浅い下調べを通じて論点を広げる。
3. **文体の雑談はメモに留める**: 好みやNG表現が自然に出たら窓口が台帳へメモするが、この段階で文体アンケートは行わない。
4. **終了宣言で要件定義書を起こす**: 依頼者が議論を終えると示したら、`handoff.md` の7欄（`records/01-requirements.md`）に整理し、承認を得る。
