# 文書作成規格 第5版 書く手順 構成案の作成

構成案の作成は、論点案を、読者が追える順に並べる段である。企画の担当が並べ方の案を出し、依頼者が決める。構成案が決めるのは、段落ごとに何を言うかと、その並べ方までである。本文の文面、段落ごとの字数、言い回しは決めない(それは執筆の自由である。common.md の方針)。

## O1 始め方

- O1.0 材料:承認済みの要件定義書と論点案(records/points.md)、author-style.md。
- O1.1 依頼者が箇条書きを出した場合は、それを出発点にする。W5.3に従って批評し、断りなく並べ替えた版で置き換えない(W5.4)。
- O1.2 箇条書きが出ていない場合は、企画の担当が並べ方の案を2〜3出す。小さい文書(小論文など)では1つでよい。案ごとに、どんな順か(例:身近な例から入る、結論から入る)を一行で添える。

## O2 書き方

- O2.1 階層は、文書全体 → 章・部 → 節・項・話題 → 段落とする。文書に存在しない階層は作らない。
- O2.2 段落ごとに、その段落で何を言うかを一行で書く。話題の名前(「〜について」)ではなく、言う内容で書く。本文の文章にはしない。
- O2.4 依頼者が指定した言い回し・定義の文面・式は、そのまま書き留める。それ以外の文面は書かない。
- O2.5 導出を含む文書では、結論の式と、導出の道筋(どの事実から、どの操作で進むか)を構成案に書く。
- O2.6 欄:段落ごとに、次の表の欄をすべて「名前: 値」で1行ずつ書く。依頼者が決めた欄には、その決めを書く(この段落はこの例から入る、ここは強調する、など)。依頼者が決めていない欄は「任せる」と書き、AIの見立てで中身を埋めない。始め方と締め方は、章・節の欄である。

| 欄 | 書く場所 | 依頼者が決めた場合の値 |
| --- | --- | --- |
| 詳しさ | 段落 | 詳しく/簡潔に/触れるだけ |
| 強調 | 段落 | 強調する点 |
| 式 | 段落 | 使う式/なし |
| 図 | 段落 | 使う図とその内容/なし |
| 表 | 段落 | 使う表とその内容/なし |
| 例 | 段落 | 使う例とその内容/なし |
| 余談 | 段落 | 置く余談と、つながる先/なし |
| 前提 | 段落 | その段落が使う既出の事柄のうち、離れた位置にあるもの |
| 始め方 | 章・節 | その単位の入り方 |
| 締め方 | 章・節 | その単位の終わり方 |

## O3 示す前に確かめること

- O3.2 順序と前提:各段落が使う語・定義・事実・形が、それより前の段落か、読者の扱える形にあるか。ない場合は、順序を変える案か、前提の段落を足す案を示す。
- O3.3 筋:隣り合う段落の間に飛躍(common.md N1.5)がないか。論証の形に欠けがないか。主張と例が現実的か(common.md N1.21)。欠けた段落は、案として示すか、尋ねる。
- O3.6 正確性:構成案に書かれた主張・式・数値・引用を、common.md N8.4に従って確かめる。

## O4 書式と承認

- O4.1 次の書式で records/outline.md に書く。案が複数あるときは、「並べ方の案」を案ごとに繰り返す。依頼者が決めた後は、決めた並べ方だけを残す。

```text
# 構成案:[文書名](版・日付)
読後に期待すること: (要件定義書から写す)
主張: (要件定義書から写す)

## 並べ方の案 A:(どんな順か。一行)

### 1 [章・節の仮題]
始め方: 任せる
締め方: 任せる
- 段落: (その段落で何を言うか。一行)
  詳しさ: 任せる
  強調: 任せる
  式: なし
  図: なし
  表: なし
  例: (依頼者が決めた例)
  余談: 任せる
  前提: 任せる
```

- O4.2 依頼者は並べ方を選ぶ。混ぜる・入れ替えるのは自由である。依頼者の答えは、窓口が該当の欄に写す(common.md N7.2 の5)。
- O4.3 構成案を示して承認を求める。承認を得たら、執筆へ進む。
