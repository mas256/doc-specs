# 文書作成規格 第4版 書く手順 author-style のテンプレート:講義型と実務型(工程1で使う)

## Y1 使い方

- Y1.1 型は、author-style のテンプレート集(common.md N3.8)のテンプレートである。author-style を新しく作るときに、テンプレートの問いへの答えの候補として示す(R3.3)。型のまま使うか、事項ごとに変えるかは、依頼者が決める。author-style の欄が記入済みの事項には、型を示さない。
- Y1.2 工程3・4は、この型ではなく、author-style.md に従う。
- Y1.3 テンプレートが持つもののうち、ロールモデル、一歩の大きさの見本、省略してよい範囲、位置の判断(common.md N3.8)は、この2つの型ではまだ定めていない。型を使う場合は、author-style-template.md の問いで尋ねる。
- Y1.4 型の方針の種別(common.md N3.3、N3.4)は、文面から決める。「〜することがある」「書けるときに書く」は任意、「多用する」「よく使う」は頻度、それ以外は通常である。目安も例もない方針(「文は流麗で、日本語として質が高い」など)を採る場合は、目安か例を依頼者に尋ねる(handoff.md N4.4 の6)。

## Y2 文書ごとに決める事項

「未記入」は、出典に定めがなく、工程1で尋ねる事項である(author-style の「未記入」と同じ扱い。「なし」とは書かない)。

| 事項 | 講義型 | 実務型 |
| --- | --- | --- |
| 向く文書 | 教科書、解説。通読して理解を積み上げる文書 | 起案書、企画書、報告、引き継ぎ書、連絡文 |
| 文体 | だ・である調 | です・ます調 |
| 語り口 | 熟練の教師の講義。呼びかけをよく使う | 未記入 |
| 始め方 | 身近な話題・直感的推測・素朴な疑問から始めることがある(任意) | これから何について述べるかを最初に示す。説明・提案では結論を先に置く |
| 進め方 | 演繹的に、ステップバイステップで進める | 結論→根拠→具体例→結論を基本に、読者が自然に追える順に並べる |
| 反復 | 読者が止まりそうな箇所で、説明や命題を別の形で述べ直す | 簡潔に書く。不要な文と重複を削る |
| 一文 | 演繹は、1回の操作で越えられる一歩ずつに分ける。流麗さを保つ | 1文に1内容。修飾を重ねすぎない |

| 締め方 | 面白さ・便利さ・他の事柄とのつながりを、書けるときに書く(任意) | 主張をもう一度示す。提案では今後の流れを書く |

## Y3 講義型

### 1.確かめられる規則

- 文体はだ・である調とする。です・ます調や砕けた口語を混ぜない。
- 係り受けと修飾を明確にする(どの語に係るかが一通りに定まらない文は違反)。
- 脇道を書くときは、扱っている事柄が属するより大きな概念とのつながりと、そこで重要である理由を本文に示す。

### 2.判断の入る方針

- 明瞭な論理の流れと、認知負荷の削減を最も重視する。
- 章や節の議論を、身近な話題・直感的推測・素朴な疑問から始めることがある。ただし、無理に作らない。
- 結論部分で、それがどれだけ面白いか・便利か・他の事柄とどう繋がるかを書けるときに書く。
- 論理はなるべく演繹的に、矛盾と飛躍なく、ステップバイステップで進める。
- 読者が扱えない形は、使う前に説明して既出にする。説明しても読後に期待することに要らない形は、出さない(common.md N1.1、N9.1 の J4)。
- 演繹は、読者が1回の操作で越えられる一歩ずつに分け、明瞭な論理にする(飛躍0件。common.md N1.5)。越えられる一歩を、それ以上細かく分けない。
- 言い換えは、読者が止まりそうな箇所で、説明や命題を別の形で述べ直すときに使う(common.md N1.13)。ディスコースマーカー(また、たとえば、しかし、すなわち、なぜなら等)を多用する。
- 熟練の教師の講義を目指し、呼びかけをよく使う。
- 文は流麗で、日本語として質が高い。
- 脇道は、扱っている事柄が属するより大きな概念で重要な場合にだけ書く。

## Y4 実務型

### 1.確かめられる規則

- 文体はです・ます調とする。だ・である調や砕けた口語を混ぜない。
- 係り受けと修飾を明確にする(どの語に係るかが一通りに定まらない文は違反)。

### 2.判断の入る方針

- 相手の視点に立ち、読者の認知負荷を限界まで下げる。
- 簡潔に書く。不要な文と重複を削る。
- 1文に1内容とする。主語と述語を明確にし、修飾を重ねすぎない。情報のまとまりごとに読点を打つ。
- 章や段落の冒頭で、これから何について述べるかを示す。
- 説明・提案では結論を先に示し、根拠、具体例の順に続ける。ただし、形式に縛られず、内容が明確に伝わることを優先する。
- 読者の扱えるものに合わせ、大前提から順に始める。専門用語を必要以上に使わず、必要なら説明する。
- 主張には理由と具体例を添え、根拠は数字や事実で示す。提案では、課題・デメリットと改善策、今後の流れも書く。
- 読みながら不要な「なぜ?」が生まれないようにする。ただし、意図して残す「引き」は除く。
