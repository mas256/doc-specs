# 要件
- お題:高校数学の公式は、導出より先に使い方から教えるべきか。
- 立場:「使い方を先に教え、導出は後に回すべきだ」という立場で書く。
- 読者:高校の数学科の教員。導出を先に教える授業に慣れていて、この立場には懐疑的。
- 到達点:読者が、この立場の根拠を2つ挙げられ、予想される反論にどう答えるかを知る。
- 視点:限られた授業時間の中で、生徒が何をできるようになるか。
- 必ず使う語:「導出」「定着」
- 文体:だ・である調。

# 本文

本論では、あなたの授業の中で重要視している導出を重んじる授業に対し、ある種の反対意見を述べるものである。
これを元に授業の見直しが行われ、生徒にとってよりよい体験が得られるようになることを願っている。

私の主張は、導出よりも先に、使い方を説明するべきだ、というものである。
その根拠3つを順に説明していく。

1つ目の根拠は学校教育の中での高校数学の立ち位置である。
高校で数学を教える意味の１つに論理的思考力を養うことがある。
その観点で、導出を重要視する視点は一定の価値があるだろう。
また、数学で導出は重要な過程であり、特に数学科に分野に進む人にとっては必要な要素である。
しかし、それは万人に言えることではないと考えている。
簡単な導出過程であれば、理解を深め、論理的思考の練習になるだろう。
一方で、難解な導出の過程は知識の定着を阻害しうる。
複雑な定理や公式の導出を前提にした授業は、生徒への負荷が大きい。
例えば平均値の定理は、高校数学の範囲内で示し得るが、大学数学の初歩的な部分に遜色ない。
そういったことは、興味を持った生徒が自主的に行うべきことで、全員に強要すべきではないのではないだろうか。
まず要求されるのはその公式を使えるようになることだろう。
そして、公式が使えることは、導出の過程でその公式が何を主張しているのかを理解することと同じである。
加えて、平均値の定理自体、言っていることはごく直感的で当たり前のことである。
それをロルの定理から教えるのは、限られた授業数の中でコストが過大だろう。

2つ目の理由として情報科が追加されたことや、探究学習が重要視されていることも挙げられる。
これらの教科は論理的思考を重視しており、数学科という1教科がこだわって厳密に論理を扱う必要もないだろう。
特に、数学で扱われる論理は悪く言えば重箱の隅をつつくようなもので、現実問題に適用されにくい。

3つ目の理由は、授業で求められているものが使い方を先に教える授業であるということだ。
例えば文系も受けるような数学の授業や工学を志す人へ向けた授業においては数学を受ける意味が違うだろう。
数学を学ぶ理由が受験のためであったり、数学を使うだけでそれを理解する必要が薄い工学分野であれば、厳密な証明は必要ではない。
誤解を恐れずに言えば、無駄な時間になっているのではないだろうか。

以上のことから、公式や定理は先に使い方を教えるべきだと考える。
