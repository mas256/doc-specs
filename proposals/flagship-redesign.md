## 1 出発点:冗長さの診断

依頼者の所感:規格は、何を書くか・どう直すかに重点があり、削る・捨てる指示が弱い。そのため冗長になりやすい。読者への寄り添い方を間違え、細かすぎる段差で議論が進む。

診断(依頼者と合意済み):

- 根本は、読者の像が前提知識だけで決まっていること(N1.1)。読者がどれだけの段差を自分で越えられるかの欄がなく、補完が要る箇所はすべて飛躍(N1.5)の候補になる。越えられる段差は、位置(後ろの章・付録ほど大きい)と再登場(一度示した変形)で変わる。
- 負担の原因の7符号(N2)は、どれも「欠け」の型で、改善の方向が足す向きしかない。レビューが符号を付け(C6.2)、改稿がその方向で直す(E3.2)ので、流れ全体が足す方向に回る。
- 削る規定はあるが、立証の負担が逆向き。C3.2・C5.6・C3.7・C4.7 の歯止め(短さだけで削らない等)は、短さ偏重の失敗への手当てとして意図して入れたものなので、単に外さない。
- 方針は「最小の変更」(core の方針の規定)で、組み直し(N2.1)は条件が狭い。指摘が箇所ごとの欠陥から始まるので、変更は部分修正にとどまり、大きな組み直しが出ない。
- 講義型の既定値(Y3 の「未知を極限まで減らす」「難解な演繹は細かく分割する」「言い換えを多用する」)が、刻みすぎと冗長さを生む。
- 実例:Integral 1.5 で、書き直しのときに Σ の説明の1文が足された。Σ は 1.2 で導入済みで、承認済みの草案は「2回目以降は説明しない」と定めていた。

## 2 規則の種類と、判断力への作用

過剰な指示は、AIの判断力を鈍らせ、品質を下げうる。規則を、判断への作用で4種類に分ける。

| 種類 | 例 | 扱い |
| --- | --- | --- |
| ① 判断の代わりをする | M2.2 の組み立ての段、M3.1〜M3.7 の「〜を飛ばさない」、講義型の既定値 | 大きく削る候補。小さいモデル向けの手順としてだけ残す |
| ② 判断の材料を渡す | 想定読者、到達点、越えられる段差、読み方、見本、判断の記録 | 残し、充実させる |
| ③ 偏りを打ち消す | 書き手と評価者を分ける、論点を足さない、自己評価しない、未確認を明示する | 残す。最小限にする |
| ④ 手続き・受け渡し | ID、台帳、書式 | スクリプトに移し、AIの読む量から外す |

- 負担の原因の分類(N2)は、評価者の物差しとして残し、書き手への禁止としては渡さない。

## 3 モデルの格と、制御の手段(決定)

- フラグシップ(Fable など):創造性を依頼者の創造性に合わせる。効くのは規則ではなく、依頼者の判断とその理由。
- ミドルレンジ:案を書く。指示に忠実で、ある程度の文章力がある。
- 軽量モデル:具体的な指示を忠実に実行する。判断の材料を漏れなく集める。何も知らない読者の代わりにもなる。

フラグシップに渡すもの:

1. 判断の記録:採った版と捨てた版の組と、選んだ理由。決定だけでなく理由を渡す(初めて見る箇所にも同じ考え方を当てられるようにするため)。
2. 価値の優先順位(例:厳密さより分かりやすさ)。
3. 依頼者が退けた案と、その理由。

- author-style の「判断の入る方針」を、規則の箇条書きから判断の記録へ作り替える方向。
- 合わせ具合は測れる:依頼者にまだ見せていない較正の素材で、フラグシップに依頼者の選択を予想させ、一致した割合を見る。外れた件の理由を判断の記録に足す。
- 依頼者の傾向から外れた案は、あまり出さない。より良いものを作るために複数案を作らせ、それを元に選び・組み合わせる形を最善とする。

## 4 工程の流れ(決定)

| 段 | 担当 | 内容 | 依頼者の承認 |
| --- | --- | --- | --- |
| 1 要件定義 | フラグシップ | 方針、読者の像、判断の記録(較正) | あり |
| 2 章立てと箇条書きの草案 | フラグシップ | 章立てと、単位ごとに伝える内容(要点) | あり |
| 3 割り振り | フラグシップ | 単位ごとの作業指示(要点、入口と出口、変える軸) | なし |
| 4 骨組みの案 | ミドルレンジ | 指定された軸に沿って複数。構え・順序・使う例・段差の方針を数行ずつ | なし |
| 5 骨組みの選択 | フラグシップ | 1〜2案を選ぶ。組み合わせてもよい | なし |
| 6 本文の案 | ミドルレンジ | 選ばれた骨組みを本文にする。要点と本文の位置の対応表を付ける。前の単位の終わり方を受け取る | なし |
| 7 選択と組み合わせ | フラグシップ | 選んだ理由を判断の記録に足す | なし |
| 8 つなぎ目の照合 | 軽量 | 用語・表記・参照 | なし |
| 9 独立したレビュー | 別の文脈のフラグシップ | 現行のレビュー規格が担う。書いた・選んだ会話の内容を引き継がない | 採否は依頼者が決める |
| 10 改稿 | 軽量 | フラグシップが書いた具体的な指示どおりに直す | なし |

- 創造性が入る場所は、段2の要点(何を書くか)と、段5・7の選択(どれが良いか)。書く担当には創造性を求めず、幅(複数案)を求める。
- 段2で承認された要点が、段3以降の正本である。
- 箇条書きの深さ:最下層を、ミドルレンジに1回の作業指示で渡す単位にそろえる。基本は章まで。漸化式・積分の教科書の規模では、節や小節まで下ろす。深さは要件定義で、分量と媒体から決める。
- 割り振りの単位が承認された階層より細かくなる場合、フラグシップが決めてよいのは要点の配分と順序だけで、新しい要点は足さない。足す必要が出たら、草案に戻して承認を得る(W2.3 と同じ扱い)。
- つなぎ目:単位の中(組み合わせた案どうし)と、単位の間(前の終わり方と次の始まり方)の両方。単位は前から順に書くので、並行できる範囲は狭まる。
- 書き手と評価者を分ける(C1.3)ことは、段9で、別の文脈のフラグシップに行わせる形で保つ。

## 5 案ごとに変える軸

単位ごとに、フラグシップが迷う軸(判断の記録に前例がない軸)を2つほど選ぶ。両端を取れば、案は最大4つ。前例のある軸は記録どおりに固定する。

| 分類 | 軸 | 両端の例 |
| --- | --- | --- |
| 入り方 | 構え | 問いから/結論から/例から/困りごとから |
| | 動機づけ | 実験から/歴史から/応用から/前置きなしで本題へ |
| 順序 | 一般と特殊 | 一般論→例/例→一般論 |
| | 論証の向き | 前提から結論へ/結論から必要なものへさかのぼる |
| 段差 | 刻み | 中間の式を全部示す/操作の名前と結果だけ |
| | 分量 | 丁寧版/簡素版/限界まで削った版 |
| 例 | 数と働き | 例1つを深く/新しい注意点を持つ例を複数 |
| | 種類 | 数値の例/図/反例/応用の場面 |
| | 位置 | 一般論の前/後/途中に挟む |
| 表現手段 | 比重 | 文章中心/式中心/図や表中心 |
| | 図の位置 | 図を先に見せる/文章の後で確かめる |
| 層 | 振り分け | 理由・例外を本文に置く/注釈に回す |
| | 厳密さ | 条件を本文で述べる/本筋は条件なしで進め、注釈で補う |
| まとめ | 回収 | POINT で要約する/次の単位への問いで終える/まとめなし |

- 変えない軸:文体(語尾、呼びかけの調子)と用語・表記。author-style で決まっている。

## 6 型(構え)について

- 型が分かりやすさを生む仕組みは2つ。構え(冒頭で主張・問い・行き先を渡すと、読者はそれを成立させようとして読む)と、予測(各段の役割の並びが読める)。起承転結は流れそのものを明瞭にとらえる。
- 一般化した原則:単位の冒頭で構えを渡す。各段がその構えに対して何をしているかを読者が言える状態を保つ。最後に回収する。
- 型は、守らせる規則ではなく、骨組みの案の候補として使う。破るときは行き先を告げる(黙って破ることだけを禁じる)。単調さは、隣り合う単位で同じ型が続くことで起きるので、型の並びも見る。
- 一般の文書への一般化は、分野ではなく読者の仕事(解説・手引き・判断・伝達・物語)で型を分ける(外部の指摘 F8)。型ごとに、構えの渡し方・越えられる段差・検証の対象の既定値を持たせる。
- 現行の O3.8・M3.10・core の方針の規定が退けているのは、型を一律に課すこと。単位ごとに候補として出し、選ぶ使い方とは衝突しない。文言の調整で足りる見込み。

## 7 要件定義の厳密化

- 言葉ではなく見本で決める(較正):AIが素材の短い一節を、段差・構え・層の違う2〜3の版で書き、依頼者が選ぶ。選ばれた版と選ばれなかった版の組と理由を、判断の記録として残す。漸化式の議論で決め手になったのは、現在の版と圧縮した版を並べて選んだ場面だった。
- 決める項目:読者の仕事(型)、越えられる段差、構えの渡し方、型を守る強さ、意図した繰り返しと読み方、層、厳密さ、分量と測り方。
- 項目は見本を主にし、言葉は見本の補足にとどめる(規則を書かせる方向に寄せない)。
- 型を選べば既定値が入り、依頼者に尋ねるのは既定値から外れる項目だけにする。較正は長い文書で、段差と構えに絞る。
- 後から直す道を設ける:レビューの不採用の理由や依頼者の反応から、判断の記録を改める(外部の提案 P11)。その値が較正で決まったか、後から直したかを記録する。
- 両立しない定めを残さない規定(R3.4)を、型の一覧の既定値と選んだ値との突き合わせにも広げる。

## 8 サブエージェントへの指示の書き方(フラグシップ向け指示書に入れる)

担当の知識は、固定の定義から、フラグシップがその都度書く作業指示へ移す。固定の定義は「指示に従う。指示にないことはしない。判断が要るときは止めて返す」程度に薄くする。

1. 判断を残さない:読者の像や好みが要る判断は、フラグシップが先に済ませる。
2. 入力を閉じる:読むファイルと行の範囲を指定する。
3. 出力の形を固定する:フラグシップが機械的に照合できる形にする。
4. 確かめ方を付ける:完了の条件を書く。
5. 止まる条件を書く。
6. 一つの指示に一種類の操作。
7. 見本を付ける:入力と出力の組を1つ。
8. 禁止は具体的に書く(「冗長にしない」ではなく「方針にない文を足さない」)。

- 「集めるのは軽量、決めるのはフラグシップ」:過剰の候補の一覧、伝えたい内容の初出の行、表記・参照の照合などは軽量モデルが漏れなく集め、採否はフラグシップが決める。
- ミドルレンジへの指示(骨組みの案・本文の案)は、上の8項目に加えて、要点・入口と出口・変える軸・変えない軸を必ず含める。

## 9 これまでに出た個別の案(位置づけは未決)

- 負担の原因に「過剰」を加える(段差・到達・一般化・層・定型・結び付かない繰り返し)。外部の指摘 F3(N2 を「支障の原因」に改め、J3 の指摘にも符号を必須にする)と一度に行う。評価者の物差しとして持ち、書き手への禁止にはしない。
- 到達の遠さを節の単位で測る:伝えたい内容が節の何行目に初めて現れるか。
- 本文・注釈の層を書く段階の規則にする(理由・例外・厳密さ・参照の案内は注釈へ)。
- 意図した繰り返しは、要件定義で挙げた読み方に結び付くときだけ正当とする。
- 方針を起案するとき、足す文が新たに生む負担を、解消する負担と比べる。負担が低の指摘は、文を足して解決しない。
- 再構成担当:欠陥ではなく単位の目的を起点に、部品(残す・削る・まとめる・並べ替える・注釈へ)を組み直す案を、試作の文つきで出す。新しい流れでは、段4〜7(骨組みの案と選択)がこの役目をほぼ吸収する。既存の本文の改稿でどう使うかは未決。
- 再検証で、方針にない追加の文と差し引きの行数を一覧にする(漸化式で、改稿の担当が足した補足が「規模:小」で通った件への対策)。
