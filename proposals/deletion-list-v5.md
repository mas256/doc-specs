# 消す規則の一覧(案。2026-11-19)

方針の草案(proposals/policy-v5-draft.md)に照らして、今の指示書の規則に扱いを付けた。窓口の案で、まだ決めていない。

- 消す:方針に要らない。または試行で害が出た。
- 変える:方針に要るが、新しい流れに合わせて書き直す。
- 残す:そのまま使う(言い回しは直すことがある)。
- 移す:指示書の本体からは出し、レビューの手順・部品・設計思想・テンプレートのどれかへ移す。

合計 233 個:残す 70、変える 82、移す 42、消す 39。

用語の固定のしかた(依頼者が承認、2026-11-19):1. 固定する語は依頼者が壁打ちで選ぶ。AIは自分で語を固定しない。書く途中で固定したい語が出たら、追記案として示し依頼者が決める。2. 定義を宣言する文は、読者がその語を初めて見るときだけ置く。規則を守るための宣言(「以下、〜の意味でだけ使う」)は書かない。3. 言い換えは、想定読者が本文の目印だけで同じものだと判断できれば認める(N1.14)。

review/ の規則(202個)は、依頼者の決定(1a)で「求めたときに使うものとして残し、規則を削る作業の中で見直す」としたので、この一覧には入れていない。

| --- | --- | --- |
| writing-angles(観点と切り口) | 消す | 切り口の案は、壁打ちで主の会話が出す |
| writing-topics(題材) | 消す | 題材は、壁打ちの広い調べ物で主の会話が集める |
| writing-planner(企画) | 変える | 論点案の作成(補強)と構成案の作成を受け持つ |
| writing-rolemodel(ロールモデル) | 残す | 論点案と、読んで直す段で、読者として読む |
| writing-writer(執筆) | 変える | 日本語の書き方は自由、よい日本語の基準を目指す |
| writing-reviser(改稿) | 変える | 読んで直す段で、AIが直すときに使う |
| writing-cutter(削る案) | 移す | レビューの回の削る手順と一緒に、後で見直す |
| review-checker(検証) | 残す | 事実の確かめ(論点案、読んで直す) |
| review-chapter、structure、collator、verifier、ui | 移す | レビューの手順と一緒に、後で見直す |
