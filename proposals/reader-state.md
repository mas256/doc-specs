# 設計メモ(案):読者の状態で判断する(2026-11-16)

- 状態:案。依頼者の確認待ち。規格の本文はまだ変えていない。
- きっかけ:依頼者の指摘「AIは言葉に惑わされすぎ。純粋にその事柄を判断する枠組みを持つ」。これまでの判断は、要素の名前(構え、例示、結び、先へのつながり、面白さ)で行っていた。名前で判断すると、名前に合う形(結びに一文添える)を作って満たしたことにしてしまう。お題2の極限の一文はその典型だった。author-style の【締め方】の問い(「面白さや他の事柄とのつながり」で終えるか)も、同じ形を誘っている。

## 原則

判断は、すべて読者の状態の違いで行う。要素の名前では判断しない。

- 文書は、読者を始点の状態から終点の状態へ移すものとする。
- ある要素の要否は、「その要素を除いた本文で、読者が終点に届くか」で決める。届くとは、読み終えた状態が終点と同じで、しかも途中に「越えられる段差」を超える一歩が残らないことである。除いても届くなら削る。届かなくなるなら残す。
- 反論も同じ枠で扱う。読者の状態(信じていること)から出る反論に耐えない箇所は、終点に届いていない箇所である。

## 読者の状態の項目

始点と終点を、同じ項目で書く。

| 項目 | 書くこと | 書き方の注意 |
| --- | --- | --- |
| 扱えるもの | 読者が既に扱える式・手順・概念・道具 | 語の一覧ではなく、扱える形で書く(例:「直線は y=ax+b で与えられる」。「傾き」という語を知っているか、ではない) |
| 経験 | 読者が実感として持っている場面 | 例:中学生は労働の経験がない。電卓の Error は見たことがある |
| 信じていること | 思い込み、当然と思っていること | 反論の源になる。例:採点者は「大人は遊びと現実を区別できる」と考える |
| 越えられる段差 | 説明なしで読者が自分で越えられる一歩の大きさ | 見本の箇所で較正する(「この一歩は越えられる/越えられない」) |
| 読み方 | 一度通して読むか、引くか、どれだけ時間をかけるか | |

終点は、上の項目のどれがどう変わるかで書く。例:お題2の終点は「扱えるもの」に「割り算を掛け算の逆として書き直し、0のときに答えがない/決まらないことを示せる」が加わり、「信じていること」から「0で割るのは禁止されているから」が消える。依頼者が求めた「その先」は、「扱えるもの」に「0に近づけて調べる」という手段が加わること、と書ける(用語を一つ知ることではない)。

## 依頼者の判断を、状態の言葉に直す

これまでの依頼者の判断は、次のように書き直せる。名前ではなく、読者に何が起きるかで書く。

| 依頼者の判断(元の言葉) | 状態の言葉 |
| --- | --- |
| 新規性 | 読者が、その説明を既に見たことがない(「扱えるもの」「経験」にない) |
| 体験・親近感 | 読者の「経験」にある場面と結び付く |
| 先へのつながり | 終点の「扱えるもの」に、次に自分で調べるための手段が加わる。用語だけを渡しても、手段は加わらない |
| 扱える範囲 | 各段差が「越えられる段差」に収まり、使う道具が「扱えるもの」にある |
| 主軸一つ、補強一つ | 同じ状態の変化を起こす要素が二つ以上あれば、一つ(要るなら補強一つ)に絞る |
| 前提は先に | 読者が後の判断に使う条件は、使う前に「扱えるもの」に入れる |
| 反論に耐える | 読者の「信じていること」から出る反論で、終点の変化が崩れない |

## 改める箇所(足すのではなく、置き換える)

1. 要件定義書の書式(handoff.md N5.1、phase-1 R2.1)
   - 第2項「想定読者と前提知識」と第6項「文書の種類と読まれ方」を、「始点の読者」(上の5項目)に置き換える。語ごとに「説明なしで使えるか」を尋ねる問い方をやめる。
   - 第3項「読後に期待すること(一文)」と第4項「全体を貫く問い」を、「終点の読者」(5項目のうち変わるもの)に置き換える。
   - 第1・5・7・9〜11項は残す。第5項(必ず入れる論点)は依頼者の決定の欄として残す。
2. author-style の第2部(判断の入る方針)
   - 形を尋ねる問い(始め方、進め方、締め方、反復と接続)を、状態の問いに置き換える。例:「読み終えた読者に、何が残っていれば良い文書ですか」「読者にどこまで自分で考えさせますか(越えられる段差をどこまで使いますか)」「読者は何があれば納得しますか」。
   - 依頼者の判断の記録のうち、文書をまたいで効くもの(上の表)は、この部に状態の言葉で置く。
   - 第1部(確かめられる規則)と第3部(用語・表記表)は、もともと言葉の形を扱う部なので、そのまま残す。
3. 削る基準(工程5、修正の型)
   - 「取り除いても成り立つか」を、「除いた本文で、読者が終点に届くか」に置き換える。例示は、除くと「越えられる段差」を超える一歩が残るなら、届かなくなるので残る。

## 確かめ方の例(今回の3題)

- お題2の電卓:除くと、「禁止か、未定義か」という問いを、読者が自分の「経験」から持てなくなる。問いを持たないまま定義の話に入る一歩は、中学3年生の「越えられる段差」を超える → 届かなくなるので残す。
- お題2の結びの極限:除いても、終点の「扱えるもの」は変わらず(用語が一つ減るだけ)、途中の段差も変わらない → 届くので削る。依頼者の求めた変化(0に近づけて調べる手段)を起こすには、近づける実験を、その手段として最初から示す必要がある。
- 入試問題Bの核:採点者の「信じていること」(大人は遊びと現実を区別できる)から反論が出て、終点(納得)が崩れる → 選び直す。
