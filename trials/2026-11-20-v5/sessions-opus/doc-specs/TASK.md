# 依頼(この会話で作る文書)

この会話では、このフォルダの指示書(文書作成規格 第5版)に従って文書を作る。AIは、最初に START.md を読み、指示書が読めと言うファイルだけを読んで、その定めどおりに進める。指示書の中で人間向けとされているファイル(README.md)は読まない。

依頼者からの依頼は次のとおり。

```text
次の小論文の問題に答える文章を書いてください。

問題:「かくれんぼう」を大人になると遊ばなくなるのはなぜか、601字以上1000字以内で論じなさい。
(早稲田大学スポーツ科学部 2019年度 一般入試 小論文)

見出しは付けない。題名は不要。文体は書き手が決める。
```
