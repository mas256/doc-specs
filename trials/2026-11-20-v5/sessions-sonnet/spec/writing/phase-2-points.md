# 文書作成規格 第5版 書く手順 論点案の作成

論点案の作成は、壁打ちで依頼者が選んだ切り口を補強する段である。新しい切り口は探さない。論点案を作るうちに切り口を変えたくなったら、壁打ちへ戻る(W2.1)。企画の担当が作り、窓口が依頼者に示す。

## Z5 手順

- Z5.1 材料:承認済みの要件定義書(選んだ切り口を含む)、author-style.md、台帳の壁打ちの行。
- Z5.2 補強の調べ物:選んだ切り口の主張を支える題材について、裏付け、具体例、一段深い調べを行う(common.md N8.10)。題材の数は、文書の大きさで決める。調べた事柄は、調べた結果の行(R)の案として返す。
- Z5.3 確かめる(依頼者に示す前に、すべての題材に当てる):
  - 事実・数値・引用・数学:企画の担当が、未確認の R の行の一覧を返し、窓口が検証担当(agents/review-checker)に「書く側の要求つき」で渡して確かめさせる(W2.11)。誤りのある題材は、誤りと分かる形で示す。
  - 読者から見て:窓口がロールモデルの担当(agents/writing-rolemodel)に、作業種別「論点案」で論点案を読ませる。見るのは、現実的か(common.md N1.21)、ロールモデルにとって身近か、そこに加わる見方が読者にとって新しいか、である。
  - 窓口は二つの結果を企画の担当に渡し、企画の担当が論点案に書き込む。結果を理由に題材を黙って外さない(外す案は、理由を添えて示す)。
- Z5.4 示して選ぶ:論点案を次の書式で records/points.md に書き(承認前は案)、窓口が承認の形で示す。依頼者が選び、承認する。使わない題材のうち価値のあるものは、別の場所に置く候補(common.md N1.6)として残す。選んだ理由・捨てた理由は、決定の行(D)として台帳に書く。

```text
# 論点案:[文書名](版・日付)
切り口: (要件定義書から写す)

論点:
- 論点: (一文。主張を支える一つの事柄)
  題材: (事実・例・話題)
  確かめた結果: (台帳の R の行の番号と状態)
  読者から見て: (現実的か、身近か、新しいか。一行)

別の場所に置く候補:
- 内容: (一文)
  置く先の案: 注釈/付録/使わない
```
