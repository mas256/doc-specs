## opus の本文

大人になると、かくれんぼうを遊ばなくなる。しかし、大人の多くは、かつてかくれんぼうを遊んだ子どもでもある。遊ばなくなったのは別の誰かではなく、同じ一人の人である。この変化の理由は、遊びたい気持ちが消えたことだけとは限らない。

かくれんぼうは、道具を使わず、場所・時間・仲間の三つだけで成り立つ遊びである。隠れる場所がなければ隠れられず、見つかるまでの時間が要り、鬼と隠れる者がそろわなければ始まらない。三つは遊びの作りに入っている。多くの遊びも、程度の差はあれ同じ三つを必要とするので、かくれんぼうは遊び全般の代表例になる。この三つをまとめて環境と呼ぶ。

大人になると、環境は変わる。場所は、日常で大人が隠れてよい所が減る。隠れる大人は目立ち、恥ずかしい。すると、考えが「大人のする遊びではない」に変わる。時間は、仕事や家事で自由な時間が細切れになる。細切れの時間は仕事や家事に回り、遊びに使うとその分が滞る。すると、考えが「遊びは無駄だ」に変わる。仲間は、同じ時間にいた学校や近所の友だちが散らばる。鬼と隠れる者がそろわず、一人でやることになる。すると、考えが「一人でやってもつまらない」に傾く。どの考えも、環境の変化への反応である。遊びたい気持ちは消えたのではなく、考えに覆われている。

環境の変化が原因なら、遊べる場所と休みのある大人は遊ぶはずである。公園も休日もあるのに遊ばない大人がいる。しかし、適切な環境は、三つが同時にそろって初めて成り立つ。子どもは、学校や近所によって三つが自然にそろう。大人は、三つを一つずつ自分で手配する。逆に、三つを確保しやすい遊びは、大人にも残る。一人遊びは、一緒に遊ぶ相手が要らず、場所と時間さえ用意すればよい。場所と時間が決まったスポーツは、仕組みが三つを用意する。

消えたのか覆われたのかは、環境を戻したときに遊ぶかどうかで分かる。消えたのなら遊ばないはずだが、覆われているだけなら遊びだす。大人向けに場所・時間・仲間を用意したかくれんぼうの催しでは、子どもがいなくても大人は遊ぶ。子どもと遊ぶ大人も、子どもが仲間になり、場所と時間もそろう場では遊ぶ。三つがそろった適切な環境を与えれば、覆いが外れ、大人はまた遊びだすだろう。

## sonnet の本文

大人がかくれんぼうを遊ばなくなるのは、成長するにつれて、遊びに没頭することを妨げるものが増えるからだと考えられる。ここでいう遊びとは、かくれんぼうのように、身体と時間と場所があれば成り立ち、遊ぶこと自体が目的となる活動である。子どもは、夕暮れまで時間を忘れて没頭した。大人は遊びができなくなるのではなく、しなくなるのである。

人はできることが増え、担う役割も変わる。その結果、本人の中に、没頭を妨げるものが三つ生じる。第一に、遊びとは別の目的があると、没頭しにくい。家族で遊園地に行けば、大人は子どもを楽しませることが最優先になる。遊びは目的を果たす手段となり、注意は遊びそのものではなく、その目的に向かう。第二に、「大人らしくない」という恥ずかしさがあると、没頭しにくい。第三に、挑戦と能力の釣り合いが崩れると、没頭しにくい。挑戦が易しすぎると、退屈するからである。子どもの頃は釣り合っていた単純な遊びも、能力が上がると釣り合いが崩れ、楽しみにくくなると考えられる。

第一から第三までの、本人の中の変化を内と呼ぶ。仕事や家事に追われる生活など、本人を取り巻く状況の変化を外と呼ぶ。疲れや時間のなさは、その生活から生じ、遊びに没頭する余力を乏しくする。内と外は、成長という一つの過程を、二つの側から見たものである。恥ずかしさや楽しみにくさは、内の変化であると同時に、周囲が大人に求めるものや、触れる娯楽の複雑さが変わるという外の変化とも捉えられる。両者は互いに作用する。疲れや時間のなさで遊ばない日が続くと、遊ぶ楽しさを思い出しにくくなり、遊びを始めるきっかけが減る。きっかけが減れば、さらに遊ばなくなる。この悪循環が、没頭の経験を遠ざけると考えられる。

疲れや時間のなさに妨げられず、恥ずかしさも感じずにいられる環境を、適切な環境と呼ぶ。この環境に、遊びを始めるきっかけと、目的や役割に縛られず自由にいられる空間が加われば、悪循環も、遊びとは別の目的も、働きにくくなる。さらに、挑戦が能力に見合うゲーム性があれば、単純な遊びも妨げになりにくい。かつて共に遊んだ友人となら、役割を離れ、きっかけも得られるので、遊園地でも、家族の場合と違い、没頭が起きることがある。これらがそろえば、かくれんぼうを含め、遊びの形を問わず、没頭は起きうる。
