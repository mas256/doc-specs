# author-style（この文書で使った時点のスナップショット。最終版）

この文書の文体設定。書き出し選び（フェーズ4 Step 1）で選んだパターンA（簡潔・常体）から起こし、読んで直す（フェーズ5）の改稿に合わせて、原因の書き方と見本を更新した。文書ごとの読者像や目的は要件定義書に置き、ここには書かない。

## 1. ベースの型
* 選択した型: 実務型（だ・である。結論 → 根拠。前置きやクッション言葉を削り、一文の厚みを保つ）

## 2. 絶対ルール・型からの差分（3〜5個）
* 文末: 常体「だ・である」。「〜と考えられる」は、推測が要る因果だけに使う。
* 一人称・距離感: 一人称は使わない。読者に話しかけず、理由を「第一に・第二に・第三に」と並べて示す。
* 原因の書き方: 「〜があると、没頭しにくい」の形で書く（「できない」は、立場の文「できなくなるのではなく、しなくなる」とぶつかるため使わない。全称の断定も和らぐ）。
* クッション・反復の抑制: 「まず結論から言うと」などの前置きや、段落末の要約の反復は書かない。
* 一文に主張は一つ。中心の語（没頭・目的・釣り合い）を文の前のほうに出す。

## 3. 避けたいNG例（1〜3個）
* 「〜と言えるでしょう」「〜ではないでしょうか」の多用
* 前の段落で述べた主張の言い換えによる水増し
* 比喩を根拠の代わりに使うこと（根拠は、因果の説明で示す）

## 4. 文体の見本（2〜3段落・理想のトーン）
大人がかくれんぼうを遊ばなくなるのは、成長するにつれて、遊びに没頭することを妨げるものが増えるからだと考えられる。ここでいう遊びとは、かくれんぼうのように、身体と時間と場所があれば成り立ち、遊ぶこと自体が目的となる活動である。子どもは、夕暮れまで時間を忘れて没頭した。大人は遊びができなくなるのではなく、しなくなるのである。

人はできることが増え、担う役割も変わる。その結果、本人の中に、没頭を妨げるものが三つ生じる。第一に、遊びとは別の目的があると、没頭しにくい。家族で遊園地に行けば、大人は子どもを楽しませることが最優先になる。遊びは目的を果たす手段となり、注意は遊びそのものではなく、その目的に向かう。第二に、「大人らしくない」という恥ずかしさがあると、没頭しにくい。第三に、挑戦と能力の釣り合いが崩れると、没頭しにくい。挑戦が易しすぎると、退屈するからである。子どもの頃は釣り合っていた単純な遊びも、能力が上がると釣り合いが崩れ、楽しみにくくなると考えられる。
