## 作業パケット(窓口 → 担当。送ったものの写し)

```xml
<作業パケット>
  <役割>企画の担当(構成案)。前回と同じ担当として続ける。新たに読むのは zip の writing/phase-3-outline.md だけ(common.md・handoff.md は前回読んだもの)。リポジトリのほかの内容は読まない。</役割>
  <目的>phase-3 の Step 1 だけを行う。採用された論点から、段落ごとの「1行の役割の並び」(骨格)を作る。要件定義書の「読後に期待すること」と骨格だけを見比べ、重複・空転の段落を統合または削除する。現状案に加えて、別の順番・統合・削除の比較案を最低1つ作る(現状が最善ならその理由を1行)。Step 2(段落の設計、03-outline.md)はまだ書かない。細部の言い回しや字数は決めない。返信は骨格案と比較案(それぞれ段落数と1行ずつ)、各案の違いと利点・弱点を1〜2行、<台帳の行>。ファイルは書かない。</目的>
  <入力>
    - 承認済みの要件定義書: records/01-requirements.md
    - 選定済みの論点: records/02-points.md(冒頭の「選定」に従う。使うのは A-3、A-1、A-2、B-1〜B-4、C-1〜C-3、C-6、D-2、A-6、A-4、E-2、E-4 のみ)
    - 依頼者の並びの指定(厳守): A-3(読み手も子どもの頃に遊んだ共通の経験)を中心に置き、その遊びの性質(A-1・A-2)を見直し、その元で論を展開する。A-4 などの内容は結論の直前あたりで使う。
    - 台帳の決定: 材料は受験生が試験の場で書ける一般的な知識だけ(数値・固有の大会名は使わない。大人向けの催しは固有名を出さずに言う)。大人に残る遊び(一人遊びや場と時間が決まったスポーツ)は、三つを確保しやすい遊びとして入れる。見出し・題名なし。601〜1000字、執筆は800〜900字目安。
  </入力>
  <文体>author-style.md はまだない。</文体>
</作業パケット>
```

## 担当の返却

使う論点: A-3 中心。A-1・A-2、B-1〜B-3、C-1〜C-3。B-4 と D-2 は同じ内容なので1か所にまとめる。A-6。C-6・A-4・E-2・E-4 は結論の直前。数値と固有名は出さない。

### 現状案(5段落、尾括型)
1. 子どもの頃にほとんどの人が遊んだかくれんぼうを思い出させ、大人になると遊ばなくなる、という問いの場面を置く(A-3)。
2. かくれんぼうは道具なしで場所・時間・仲間だけで成り立ち、三つが遊びの作りに入っている。だから遊び全般の代表例になる(A-1、A-2)。
3. 大人になると場所・時間・仲間のそれぞれが変わり、遊びへの気持ちや考えもその変化に応じて動く(B-1〜B-3、C-1〜C-3)。
4. 公園も休日もあるのに大人が遊ばないのは、三つが同時にそろわないからである。子どもは三つが自然にそろい、大人は一つずつ手配する。逆に、一人遊びや場と時間の決まったスポーツは三つを確保しやすいので、大人にも残る(B-4、D-2、A-6)。
5. 気持ちが消えたのか覆われたのかは、環境を戻したときに遊ぶかどうかで分かる。大人向けに三つを用意した催しでも、子どもと遊ぶ場面でも、大人は遊ぶ。三つがそろえば大人はまた遊びだす(C-6、A-4、E-2、E-4)。
- 利点: 依頼者の並びにそのまま沿う。答えを先に言う入り方にならない。
- 弱点: 答えが最終段落まで出ない。5段落目に判定基準、事例、結論が入り、役割が重い。

### 比較案1(5段落、頭括型)
1. A-3 と、答えの方向(気持ちが消えたからではなく、環境が変わって覆われたから)を先に言う。
2〜5. 現状案の 2〜5 と同じ。
- 利点: 採点者が答えを早く読める。
- 弱点: 第1段落の答えと第5段落の結論が重なる。1段目で「覆われた」と言い切ると、書き手の思い込みと読まれる恐れがある。

### 比較案2(4段落、統合型)
1. A-3 から入り、性質と代表例の理由まで一段で言う(A-1、A-2)。
2〜4. 現状案の 3〜5 と同じ。
- 利点: 1段落あたりの字数に余裕が出る。流れが速い。
- 弱点: 第1段落が重く、A-3 が性質の説明に埋もれる。

### 重複・空転の整理
- B-4 と D-2 を1か所にまとめた。C-6 は事例の直前に置いた。E-2・E-4 は A-4 と同じ段落で「同じ型」としてまとめた。選定で外したものは入れていない(F-4・F-5 は字数が余れば候補)。

### 推薦(担当の見立て)
現状案。答えを早く示したい場合は比較案1。

## 窓口の扱い

- 担当が振った Q-9 は既に使っているので、Q-10 として台帳に載せる。
- 窓口の点検(要件定義書の「読後に期待すること」と骨格だけを見比べた):
  - 現状案の第1段落は、問いを置くだけなら「前進のない前振り段落」(phase-3)になりうる。
  - 比較案1の弱点「第1段落の答えと第5段落の結論が重なる」は、依頼者の主張(なぜ遊ばなくなるか)と結論(環境を与えればまた遊びだす)が別の内容なので、第1段落に主張だけ、第5段落に結論だけを置けば避けられる。「〜と考える」と主張として示せば、思い込みに見える入り方にもならない。これを組み合わせ案(d)として依頼者に示す。
