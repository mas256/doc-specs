# 執筆の担当(書き出しの組み直し)とのやりとり

## 作業パケット(窓口 → 担当。送ったものの写し)

```xml
<作業パケット>
  <役割>執筆の担当。前回と同じ担当として続ける。新たに読むファイルはない。</役割>
  <目的>書き出し(①②)を1案に組み直す。records/04-opening-candidates.md の末尾に「組み直し案」として追記してよい(既存の3パターンは消さない)。返信は、組み直した①②(字数つき)、どのパターンのどの部分を使い何を変えたかの一覧(Before/After)、焼き込むルール(3〜5個)、<台帳の行>。git の操作はしない。</目的>
  <入力>依頼者の決定と窓口が整理した判断の基準5つ(台帳の行 38)。組み直しの方針: 土台は A。①は A の重なりを解き、C の運びを取り入れる。②は A を土台にする。構成案①②の設計と注意点は厳守。①では答えを言わない。</入力>
  <文体>author-style.md はまだない。上の基準と、A のルールを土台にする。</文体>
</作業パケット>
```

## 担当の返却

組み直した①②(①112字、②189字、合計301字。③〜⑤に使えるのは約499〜599字)は records/04-opening-candidates.md の末尾「組み直し案」のとおり。

使った部分と変えた点:
- ① 1文目: C の「大人になると、かくれんぼうを遊ばなくなる。」をそのまま使った。
- ① 2文目: C の「しかし、大人はかつてかくれんぼうを遊んだ子どもでもある。」→「しかし、大人の多くは、かつてかくれんぼうを遊んだ子どもでもある。」(全称を避けた)
- ① 3文目: C の「遊ばなくなったのは別の誰かではなく、同じ一人の人である。」をそのまま使い、A の重なりをこの一文に解いた。
- ① 4文目: A の「この変化の理由は、遊びたい気持ちが消えたことだけとは限らない。」を使った。C の問いと「かもしれない」は基準2・3で外した。
- ②: A のまま。基準の点検(問い掛けなし、控えめな語尾なし、前置きなし、代表例の理由は明示、定義は言い切り)。

焼き込むルール:
1. 文末は「だ・である」。「のである」は事実の言い切りに限り、重ねない。
2. 論は言い切りで運ぶ。修辞の問い掛け(「〜のだろうか」)は使わない。問題提起も、言い切りの分かれ目(「〜とは限らない」)で示す。
3. 「かもしれない」「だろう」は、確かめていない点にだけ使う。根拠のない控えめな語尾は付けない。
4. 前置き(「注目したいのは」)と、論じ方を語る言い方(「〜と呼ぶことにする」)を入れない。用語の定義は「〜と呼ぶ」と言い切る。
5. 向きを変えるときは「しかし」を一文の頭に置く。一人称・呼びかけは使わず、段落末で内容を言い換えて繰り返さない。

<台帳の行>
- [決定] [全員] [承認済] 書き出しは小論文の性質から部分的に作り直す(基準5つ)
- [案(P)] [依頼者] [議論中] 組み直し案(A 土台+C の運び)。合計301字。承認されれば①②を本文冒頭に採用し、5ルールを author-style.md の初期値として確定する
- [成果物] [全員] [完了] records/04-opening-candidates.md に「組み直し案」を追記
- 前回の問い掛けについての Q は、問いを置かない方針になったため不要
- 要確認事項なし。構成案の変更提案(C)なし
</台帳の行>

## 窓口の扱い

- 決定は台帳の行 38 に記録済みなので重ねない。組み直し案を P-9 として載せる。結論の「だろう」は依頼者の結論の形(「また遊びだすだろう」)なので、ルール3と食い違わないことを窓口が確かめた(結論は予測であり、確かめていない点に当たる)。
