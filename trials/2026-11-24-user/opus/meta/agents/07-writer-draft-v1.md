# 執筆の担当(初稿)とのやりとり

## 作業パケット(窓口 → 担当。送ったものの写し)

```xml
<作業パケット>
  <役割>執筆の担当。前回と同じ担当として続ける。新たに読むのは author-style.md だけ。</役割>
  <目的>records/04-draft-v1.md に初稿を書く。①②は組み直し案をそのまま使い(一字も変えない)、③〜⑤を構成案どおりに書き足して5段落の本文にする。ファイルには本文だけを書く(見出し・題名・メモを入れない。段落は空行で区切る)。返信は、本文、字数(改行を除く全体と段落ごと)、構成案の各段落の設計と注意点をどう満たしたかの短い対応表、<台帳の行>。git の操作はしない。</目的>
  <入力>承認済みの構成案(W-3・W-4 の直し入り。④は「覆われる」の根拠にせず、反例への答えと残る遊びにとどめる。⑤の根拠は「環境を戻すと遊ぶ」。⑤で子どもと遊ぶ大人の動機を書かない)。承認済みの要件定義書・選定済みの論点。台帳の決定(「かくれんぼう」、見出し・題名なし、一般的な知識だけ、601〜1000字で800〜900字目安)。</入力>
  <文体>meta/author-style.md(全項目)。</文体>
</作業パケット>
```

## 担当の返却

初稿を records/04-draft-v1.md に書いた(5段落、本文だけ、①②は組み直し案のまま)。本文はファイルのとおり。

字数(改行を除く): 全体 900字。①112、②189、③226、④179、⑤194。最初に書いた版は1030字で上限を超えたため、③④⑤を削った。

構成案との対応表(担当の返却より):
| 段落 | 満たし方 |
|---|---|
| ① | 組み直し案のまま。「とは限らない」で分かれ目を示した。答えは書いていない |
| ② | 組み直し案のまま。以降の段落で理由も定義も繰り返していない |
| ③ | 三つとも「変化→すると→考え」の順。最後に「消えたのではなく、考えの下に覆われ、表に出なくなっている」 |
| ④ | 反例を先に出し「三つが同時にそろって初めて」で答えた。一人遊びとスポーツは確保しやすさに絞った。「覆われる」の根拠にしていない |
| ⑤ | 基準→事例(子どものいない催しを先、子どもと遊ぶ大人を同じ型として)→結論1文。動機・固有名・数値なし |

author-style との点検: 問い掛け、「かもしれない」、前置き、「〜と呼ぶことにする」、「のである」の重ね、段落末の言い換えの繰り返しがないことを確かめた。

<台帳の行>
- [成果物] [全員] [完了] records/04-draft-v1.md を作成(900字、5段落)
- [変更(C)] [依頼者] [未決] 字数に収めるため、構成案の次の2点を省いた。④:「二つがあっても、残る一つが同時にそろわなければ遊べない」と、末尾の「大人に遊びが残るかどうかは、三つの確保のしやすさで分かれる」。③:「他人の敷地や店には入れず、物陰にいれば不審に見える」。戻すと900字を超える(1000字以内には収まる)
- 要確認(Q)なし
</台帳の行>

## 窓口の扱い

- 窓口が字数を数え直した(改行を除き 112・189・226・179・194、計900字)。担当の数と一致した。
- 変更 C を C-1 として台帳に載せ、依頼者に尋ねる(Q-14)。
