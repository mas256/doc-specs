# ロールモデルの担当(読んで直す Step 3:細部監査)とのやりとり

## 作業パケット(窓口 → 担当。送ったものの写し)

```xml
<作業パケット>
  <役割>ロールモデルの担当(読者視点)。前回と同じ担当として続ける。新たに読むのは原稿と author-style.md(指定の部だけ)。構成案・論点案・台帳は読まない。</役割>
  <目的>phase-5 の Step 3 の順番どおりに返す。①全体の読後感(2〜3行)→ ②読者の視点で引っかかる個別箇所(論理の面の基準を含む)→ ③表現の点検(common.md の表現の面の基準を一つずつ、本文の文に頭から当て、当たった文をすべて挙げる。「当たる文なし」も明記)。各指摘に番号、段落、原文、引っかかり、直し方の向き(削る→言い換え→足す)。直した本文は書かない。ファイルは書かない。最後に <台帳の行>。</目的>
  <入力>原稿 records/04-draft-v2.md(927字)、要件定義書(前回読んだもの)。</入力>
  <文体>meta/author-style.md の 1〜4 だけ。author-style に沿った書き方は誤指摘しない。</文体>
</作業パケット>
```

## 担当の返却

担当の注記: author-style.md は全体を読んだ(5・6 は「まだない」のみ)が、監査には使っていない。

返却の中身(①全体の読後感、②の5件、③の基準ごとの当たり、優先度の目安、台帳の行)は、records/05-review.md の「Step 3」にそのまま表として写した。表に入れなかった担当の記述:
- 優先度の目安: 最優先は ②-1、②-3、②-2。次点は ③-11(削る)、③-1(削る)、③-14(言い換え)。
- 字数: 927字で上限まで73字。足す案(②-2・②-4)と削る案(③-1・③-9・③-11)を相殺すれば収まる。
- ②-2 の直し方の例: 「隠れてよい所が減る→隠れる大人は目立つ」。足せないなら「すると」を言い換えて因果の言い切りを少し弱める。
- ②-4 の例: 「大人のかくれんぼう大会」など(事実確認は別途)。
- ②-5 の例: 「仲間の役が要らず、場所と時間さえ用意すればよい」。
- <台帳の行>: W(②-1)、W(②-2)、W(②-3)、W(②-4・②-5)、C(削る案・言い換え案)、Q(①の見本の文を残すか)。担当の振った番号は台帳と重なるので、窓口が W-7〜W-10、P-13、Q-17 に振り直した。
