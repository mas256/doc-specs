# author-style（70%初期値）

## 1. ベースの型
* 選択した型: 実務型（常体・小論文向けアレンジ）

## 2. 絶対ルール・型からの差分
* 文末: 常体「だ・である」で統一する。「〜だろう」「〜してみよう」などの推量・呼びかけ表現は使わない。
* 運び: 段落冒頭で結論や要点を先に言い切り、根拠と具体例で支える。
* テンポ・文の長さ: 1文は55字以内を目安に短く切り、主語と述語のねじれを防ぐ。

## 3. 避けたいNG例
* 前置きやクッション言葉（「一般的には〜と言える」「まず考えてみたい」など）
* 根拠のない現代社会批判や教訓めいた締めくくり（「大人も童心に返るべきだ」など）
* 過度な比喩や感嘆符

## 4. 文体の見本（採用した書き出し）
大人が「かくれんぼう」を遊ばなくなるのは、単に多忙や羞恥心のせいではない。この遊びの本質は、必ず見つけてもらえるという安心感のもとで姿を消し、再発見されて他者とのつながりを確かめる点にある。鬼が数を数える間に隠れ手が身を潜め、見つけ手に見つかって笑い合う体験は、無条件の信頼に支えられている。では、なぜ成長とともにその条件が失われ、この遊びは成立しなくなるのか。

第一の要因は身体と空間の制約であり、さらに本質的なのが「隠れる」行為の意味変容である。体格が大きくなった大人は、子どものように押し入れや狭い物陰へ身を潜めにくく、公私の境界が厳格な生活空間では隠れ場そのものが限られる。しかしより決定的なのは、社会生活の中で「隠れる」の性質が変わる点だ。大人にとって隠すことや隠れることは、無邪気な一時退避ではなく、体面を保つための本音や欠点の秘匿、あるいは他者の視線や責任からの防衛を意味するようになる。見つけられて笑い合う快楽は、露見への警戒に取って代わられるのである。

## 6. 著者共通の表記癖
* 「こと」「もの」はひらがなで書く。
* 固有の用語（「鬼」「隠れ手」「見つけ手」）は定義を並べず、文脈の中で自然に用いる。
