# author-style(この文書の時点。2026-11-24)

このファイルは著者固有の文体設定です。文書ごとの読者像や目的は「要件定義書」に置き、ここには書きません。

## 1. ベースの型
* 選択した型: 実務型(parts/style-presets.md)を土台に、思索・エッセイの運び(「しかし」で向きを変え、言い切る)を一部取り入れた。書き出し選びで、依頼者が「小論文という性質の文から判断して、部分的な作り直し」を選んだ(3パターンからの組み直し)。

## 2. 絶対ルール・型からの差分
* 文末は「だ・である」にする。「のである」は事実の言い切りに限り、重ねない。
* 論は言い切りで運ぶ。修辞の問い掛け(「〜のだろうか」)は使わない。問題提起も、言い切りの分かれ目(「〜とは限らない」)で示す。
* 「かもしれない」「だろう」は、確かめていない点にだけ使う。根拠のない控えめな語尾は付けない。
* 前置き(「注目したいのは」)と、論じ方を語る言い方(「〜と呼ぶことにする」)を入れない。用語の定義は「〜と呼ぶ」と言い切る。
* 向きを変えるときは「しかし」を一文の頭に置く。一人称・呼びかけは使わず、段落末で内容を言い換えて繰り返さない。

## 3. 避けたいNG例
* 「注目したいのは、〜という点だ。」(中身のない前置き)
* 「何が変わったのだろうか。」(修辞の問い掛け)
* 「〜という説明だけでは足りないかもしれない。」(根拠のない控えめな語尾)

## 4. 文体の見本(書き出し選びで採用した段落)

大人になると、かくれんぼうを遊ばなくなる。しかし、大人の多くは、かつてかくれんぼうを遊んだ子どもでもある。遊ばなくなったのは別の誰かではなく、同じ一人の人である。この変化の理由は、遊びたい気持ちが消えたことだけとは限らない。

かくれんぼうは、道具を使わず、場所・時間・仲間の三つだけで成り立つ遊びである。隠れる場所がなければ隠れられず、見つかるまでの時間が要り、鬼と隠れる者がそろわなければ始まらない。三つは遊びの作りに入っており、どれかが欠けると遊べなくなる様子がはっきり見える。多くの遊びも、程度の差はあれ同じ三つを必要とするので、かくれんぼうは遊び全般の代表例になる。この三つをまとめて環境と呼ぶ。
