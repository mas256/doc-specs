# 執筆の担当(初稿)とのやりとり

## 作業パケット(窓口 → 担当。送ったものの写し)

```xml
<作業パケット>
  <役割>執筆の担当。前回と同じ担当として続ける。新たに読むのは author-style.md だけ。</役割>
  <目的>records/04-draft-v1.md に初稿を書く。①②は組み直し案をそのまま使い(一字も変えない)、③〜⑤を構成案どおりに書き足して5段落の本文にする。ファイルには本文だけを書く(見出し・題名・メモを入れない。段落は空行で区切る)。返信は、本文、字数(改行を除く全体と段落ごと)、構成案の各段落の設計と注意点をどう満たしたかの短い対応表、<台帳の行>。git の操作はしない。</目的>
  <入力>承認済みの構成案(W-3・W-4 の直し入り。④は「覆われる」の根拠にせず、反例への答えと残る遊びにとどめる。⑤の根拠は「環境を戻すと遊ぶ」。⑤で子どもと遊ぶ大人の動機を書かない)。承認済みの要件定義書・選定済みの論点。台帳の決定(「かくれんぼう」、見出し・題名なし、一般的な知識だけ、601〜1000字で800〜900字目安)。</入力>
  <文体>meta/author-style.md(全項目)。</文体>
</作業パケット>
```
