## 議論の進め方(次のチャットで守ること)

11/16 の後半、AIの回答の質が下がった。原因はAIの側にあった:指摘のたびにすぐ新しい枠組み(表と新しい用語)を作った/依頼者の短い指示の意味を確かめずに推測で埋めた/議論が決着する前にファイルを書いた/会話が長くなり、前の決定を正確に参照できなくなった。次からは次のとおり進める。

- 指示を受けたら、まず理解を1〜2文で言い直し、合っているかを確かめてから考える。
- 案は1つずつ、小さく出す。新しい用語は、どうしても要るときだけにする。
- 枠組みより先に、具体的な1例で判断して見せる。
- 合意するまで、規格や設計メモのファイルを書かない(試行の記録は除く)。
- 基準は、依頼者の実際の判断(下の「依頼者の判断」)から作り、新しい枠組みはそれを説明できるかで確かめる。
