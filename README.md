# doc-specs（文書作成規格 第5版・改訂版）

AIと人間が協働して、筋の通った自然な文書を作成・レビューするための軽量仕様書群です。

## 設計の芯
* **作り手は依頼者（人間）、AIは伴走者**: AIに丸投げせず、目的・読者・文体の主導権を人間が持ちます。
* **骨格から細部へ**: 構成や論の流れ（骨格）を先に固めてから、表現やエラー探し（細部）に進みます。
* **単純に始め、軽量モデルでも動く**: `Sonnet` / `Haiku` クラスや通常のWebチャット（なりきり運用）を基準に、読む量を最小限に抑えています。
* **重厚さを殺さず、冗長・重複だけを削る**: 一文を短く縛るのではなく、反復・クッション言葉・役割のない段落を削ぎ落とします。

## どこから始めるか
* **初めて使う方・人間向けガイド**: [MANUAL.md](MANUAL.md) を参照してください（短い文書向けの「最短コース」から始められます）。
* **AIに渡す入口**: 会話の最初に [START.md](START.md) を渡します。

## ディレクトリ構成
* `START.md` — AI向けの入口（依頼分類 A〜F、環境・モデル別の最小読み込み制御）
* `common.md` — 全担当共通の原則・品質基準・担当制約
* `orchestrator.md` — 窓口専用の進行・承認・骨格ゲート・台帳ルール
* `handoff.md` — 成果物フォルダ構造・台帳固定テンプレート・要件定義書7欄・作業パケットの正本
* `author-style-template.md` — 軽量版文体テンプレート
* `parts/` — AIが裏で書き出しパターンを作るための薄い索引とマイクロ見本
* `writing/` — 執筆フェーズ手順（`phase-1` 〜 `phase-5`）
* `review/` — 第5版に統合された形式レビュー手順（骨格先行＋細部監査）
* `agents/` — 各専門担当の薄い定義（役割・読む範囲・入出力）
* `docs/` — 設計思想（`DESIGN.md`）および過去の経緯・先祖返り禁止リスト（`DESIGN_HISTORY.md`）
