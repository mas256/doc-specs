# author-style の型（プリセット）

`author-style.md` のベースとして選ぶ標準の型です。

## 講義型（納得・理解重視）
* **文末**: です・ます（または丁寧な問いかけ＋常体の混合も可）
* **運び**: 背景・問い → 具体例 → 抽象化・まとめ
* **特徴**: 読者が「なぜそうなるか」を腑に落ちるよう、橋渡しの一文を丁寧に入れる。

## 実務型（伝達・判断重視）
* **文末**: だ・である（または簡潔なです・ます）
* **運び**: 結論 → 根拠・箇条書き → 次のアクション
* **特徴**: 前置きやクッション言葉を削り、一文の厚みを保ちつつ判断材料を前に出す。
