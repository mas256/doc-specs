# 論点案:かくれんぼう小論文(v2・2026-11-20。案。要件定義書 v3 の切り口に合わせて組み直した。前の版は records/work/points-v1.md)
切り口:
  着眼点: 隠れる喜びは、「見つけてもらえないかもしれない」という不安と、「最後には見つけてもらえる」という保証の組から生まれる。保証は、鬼が探し続けるという遊びの決まりと、遊びの外にいる大人(夕方に迎えに来る親など)が支えている。
  主張: 大人がかくれんぼうをしなくなるのは、飽きたからではなく、遊びの中で見つけてもらえないことが大人には災厄でなくなり、不安と保証の組が成り立たず、隠れる喜びが生まれなくなるからである。

論点:
- 論点: 隠れる喜びは、「見つけてもらえないかもしれない」という不安と、「最後には見つけてもらえる」という保証の組から生まれる。
  題材: 物陰で息をひそめ、足音が近づき、見つかって声を上げる。喜びは、見つかるかどうか分からない緊張が、見つかることでほどける瞬間にある(誰もが知る経験)。長く見つからないことを楽しむ面もあるが、それも最後には見つけてもらえると分かっているから楽しめる、と「最後には」で限る(W-10)。
  確かめた結果: 事実の主張なし(日常の観察)
  読者から見て: 前回の読み(論点1)を反映する。現実的で身近。新しいのは「喜びを不安と保証の組から見る」見方。「必ず」が強すぎるとの指摘(W-10)は、「最後には」に改めた。組み直した形は、確かめ待ち(ロールモデルの担当がもう一度読む)

- 論点: その保証は、鬼が探し続けるという遊びの決まりと、遊びの外にいる大人が支えている。
  題材: 鬼は全員を見つけるまで探し続ける。夕方になれば、親が迎えに来る、または呼びに来る。遊びの中の決まりが保証をつくり、遊びの外の大人が最後にそれを支える(日常の観察)。
  確かめた結果: 事実の主張なし(日常の観察)
  読者から見て: 前回の読み(論点2)を反映する。現実的で身近。保証の最後を外の大人が支えるという見方は、読者にとって新しい

- 論点: 子どもにとって、見つけてもらえないことは災厄でありうるので、不安は本物であり、保証が喜びになる。
  題材: 隠れたまま忘れられ、気づけば皆が帰っていた、という子どもの経験(日常の観察)。ウィニコットの「隠れることは喜びだが、見つけられないのは災厄だ」という言葉(名前と言葉だけを使い、書名・年は書かない。D-7)。「災厄」は初めて出す位置で、皆が帰ってしまい隠れたまま忘れられることと具体で示す(AP7)。子どもの場合の言葉として使い、大人の心理一般に広げない。
  確かめた結果: R-1 確認済(出典はウィニコット本人の論文の句。逐語と頁は一次の本文で未照合。A-1)。R-6 誤り(一部)(同句が1963年の論文にある。クレア説は採らない)。子どもの経験の部分は、事実の主張なし(日常の観察)
  読者から見て: 確かめ待ち

- 論点: 大人には、遊びの中で見つけてもらえないことが災厄にならず、不安が消えるので、不安と保証の組が成り立たない。
  題材: 大人は、隠れ続けて誰も来なければ、自分で出て行けばよい。置いていかれても、一人で帰れる(日常の観察)。見つけてもらえないことで失うものが小さければ、「最後には見つけてもらえる」という保証も、ほどける緊張を生まず、喜びにならない。言うのは「遊びの中で」見つけてもらえないことに限り、大人は何も怖くない、とは言わない。
  確かめた結果: 事実の主張なし(日常の観察)
  読者から見て: 確かめ待ち

- 論点: 大人同士の休日の集まりでも、見つかるかどうかが自分にとって軽いので、盛り上がりにくい。
  題材: 大人同士が集まってかくれんぼうをしても、見つからなくても出て行けばよく、見つかっても安堵がほとんどない。互いに保証の役を引き受けても、不安がないので喜びが生まれない(日常の観察。W-6 への答え。A-5)。
  確かめた結果: 事実の主張なし(日常の観察)
  読者から見て: 確かめ待ち

- 論点: 大人が加わるかくれんぼうは、この筋の反例ではなく裏づけである。親や祖父母は、子どもの不安を受け止め、保証を与える側に回る。大人が集まる催しは、見つかるかどうかに別の重さを作り直している。
  題材: (1)親や祖父母が子どもとするかくれんぼう(A-2)。大人は、鬼として最後には必ず見つける。子どもの不安を受け止め、保証を与える側にいる。大人自身が保証に守られていなくなる遊びではない(日常の観察)。(2)大人が集まるかくれんぼうの催しと世界選手権(R-4、R-9)。広い会場、制限時間、勝ち負けで、見つかるかどうかに重さを作り直す。制限時間と勝ち負けは、無人島の催しとスタジアムの催しで確認済みである。世界選手権は、存在と入賞までを書き、規則の中身は書かない。本文では、主催者名・数値を書かない(D-7)。スタジアムの催しは大人向け限定ではないので、例に使うなら「大人も参加できる」と書くか、無人島の催しにとどめる(R-4)。
  確かめた結果: (1)事実の主張なし(日常の観察)。(2)R-4 確認済(スタジアムは子どもから大人までが対象)。R-9 確認済(一部:スタジアムの催しの主催者名と、世界選手権の規則の中身は確かめていない。どちらも本文に書かない)
  読者から見て: 前回の読み(論点5)を反映する。親・祖父母の例は読者に最も身近な反例で、現実的。催しも現実的。世界選手権は競技の面が強く、遊びとして扱ってよいかを気にする読者がいる(「勝ち負けの重さを作り直す例」として使えば、競技の面が筋に合う)。「どちらも」でまとめる見方は新しい。鬼の側で保証を与える形(親・祖父母)と、別の重さの作り直し(催し)は新しい形なので、確かめ待ち(ロールモデルの担当がもう一度読む)

ロールモデルの担当の弱いところ(W-6〜W-10)の扱い:
- W-6(大人同士の休日の集まりで遊ばない理由がない):論点5を新しく置いた。見つかるかどうかが自分にとって軽いので盛り上がりにくい、と答える(A-5 の(a))。
- W-7(遊びの隠れと「予定にない不在」の場面が合わない。三歩目が二歩目の言い直し):「現実の捜索」の筋をやめ、場面を遊びの中に戻した(論点3、4)。理由を「大人には遊びの中で見つけてもらえないことが災厄でなくなる」に置き、二歩目(災厄でなくなる)と三歩目(組が成り立たない)を別の事柄にした。
- W-8(「保証を与える側」と「周りに当てにされる側」が混ざる。勤務中の人の例が強い):勤務中の人の例をやめた(A-5)。「保証を与える」は、親や祖父母の例(論点6)でだけ使い、語を分けた。
- W-9(「受ける側から与える側へ」が、大人は保証を受けないと一般化して読める。「責任があるから遊べない」では「忙しい」の仲間):主張の筋を「見つけてもらえないことが災厄でなくなる」に替え、受ける側/与える側の対を、主張から外した。責任や忙しさとは別の理由になる。
- W-10(「必ず見つけてもらえる」は断定が強い):「最後には見つけてもらえる」に限った(論点1。要件定義書 v3 の語句どおり)。
